# eggbabe 蛋宝宝小程序 V2 Preview

这是基于现有 MVP 增量升级的微信小程序 V2.11 Preview，可直接将本文件夹导入微信开发者工具。最新规格见 `docs/蛋宝宝小程序_V2_PRD.md`，数据结构与云端接入见 `docs/V2_DATA_MODEL.md`、`docs/V2_CLOUD_SCHEMA.json` 和 `docs/V2_IMPLEMENTATION.md`。

公开仓库：<https://github.com/octopusgump/eggbabe-miniprogram>

## 已完成的核心闭环

微信授权进入 → 输入激活码 → 绑定唯一蛋宝宝 → 轻触 / 长按互动 → 获得露珠与装饰道具 → 到达预设破壳日 → 生成唯一收藏卡 → 在生活场景继续收集系列收藏卡。

本版严格遵循最新 PRD：孵化期只展示蛋形，不展示背景场景，也不提供场景选择或切换入口。

## 本地预览

1. 打开微信开发者工具，导入 `02_MiniProgram_MVP_20260710_GPT` 文件夹，而不是单独导入 `miniprogram/`。
2. 未配置正式 AppID 时可保留 `touristappid` 进行界面预览。
3. 勾选隐私政策后点击“微信授权并进入”。如果拒绝授权，页面会停留在进入页。
4. 使用下面任一演示激活码：
   - `DEMO-RABBIT`：获得玉兔，默认 7 天后破壳。
   - `DEMO-KOI`：获得锦鲤，默认 7 天后破壳。
   - `HATCH-NOW`：立即进入待破壳状态，用于检查收藏卡、档案和对话闭环。
   - `INVALID`、`USED`、`FULL`、`PAUSED`：分别检查四类异常提示。
5. 如需回到未添加蛋状态，在“我的 → 账号 → 重置本地体验数据”中清除本地演示数据。

## 展会快速体验

首页右上方提供“展会快速体验”入口。点击后会进入独立 `demo` 数据空间，直接生成一只已破壳的演示玉兔，并进入草地、雪地、房间、海边、桌面、屋顶六个生活场景。展会页面全部直接使用 `assets/scenes/*_with_egg.jpg` 玉兔成品图，每个场景包含 3 个可点击互动点。

从六场景页面点击“退出展会体验并恢复数据”，或回到首页点击“退出体验”，即可恢复进入前的孵化状态。

## 当前实现边界

- 未配置云环境时，本地激活与展会体验自动使用 `demo` 数据空间，方便预览且不会伪装成正式数据。
- 正式模式已有登录、激活、服务器时间、收藏卡生成、掉落、埋点、露珠账本与背包的云函数骨架；上线仍需创建集合/索引、部署函数并配置正式 H5 域名。
- 商店仅使用互动获得的露珠兑换纯装饰道具；小程序内没有真钱支付、充值、订单、退款、战力、多宠物、排行榜、交易、广告换币或语音功能。
- 收藏卡“保存图片”使用微信 Canvas 与相册能力；开发者工具里建议同时用真机验证授权流程。

## 用户资料与公开 ID

- 优先使用微信授权返回的昵称、头像、性别和地区；微信没有返回的字段保持空白，不填充演示数据。
- 用户公开 ID 格式为 `EB-注册日期-毫秒时间编码-随机唯一段`，首次注册时生成并持久化，同一注册时刻的用户由随机段区分。
- 正式服务端接入时仍应给公开 ID 建立唯一索引，并在极低概率碰撞时重新生成；前端格式无需改变。

## 校验

在项目根目录运行：

```bash
node scripts/verify-project.js
node scripts/verify-v2.js
node scripts/verify-h5.js
node scripts/verify-v211.js
```

校验会检查页面四件套、JSON、组件引用、工程根目录设置，以及最新 PRD 禁止的孵化场景页面是否仍被编译。
