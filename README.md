# eggbabe 蛋宝宝小程序 V2 Preview

这是基于现有 MVP 增量升级的微信小程序 V2.26 Preview，可直接将本文件夹导入微信开发者工具。当前产品规范为 `docs/蛋宝宝小程序_V2_PRD.md` v2.28；发布门禁见 `docs/蛋宝宝普通小程序_合规与提审清单.md`，前后端边界见 `docs/蛋宝宝小程序_技术与数据接口规格.md`。`V2_IMPLEMENTATION.md`、`V2_DATA_MODEL.md`、`V2_CLOUD_SCHEMA.json` 和收藏卡旧文档均为历史记录，不代表普通版要求。

公开仓库：<https://github.com/octopusgump/eggbabe-miniprogram>

## 已完成的核心闭环

微信授权进入 → 输入激活码 → 绑定唯一蛋宝宝 → 命名 / 轻触 / 长按 / 说话 / 自由陪伴 → 到达可承接破壳时刻 → 生成一蛋一份的收藏卡 → 在生活场景获得纯内容反馈并继续对话。

孵化期使用统一的小房间场景，不提供场景选择或切换；前端支持四季底图、上海天气粒子和昼夜光线三层表现，正式环境数据由 CTO 侧下发。

## 本地预览

1. 打开微信开发者工具，导入 `02_MiniProgram_MVP_20260710_GPT` 文件夹，而不是单独导入 `miniprogram/`。
2. 未配置正式 AppID 时可保留 `touristappid` 进行界面预览。
3. 勾选隐私政策后点击“微信授权并进入”。如果拒绝授权，页面会停留在进入页。
4. 本地验收码不区分大小写，首尾空格会自动忽略：
   - `FUHUAQIAN`：固定绑定玉兔，按正常生命周期预览普通陪伴流程。
   - `FUHUAHOU`：固定绑定玉兔，直接进入已破壳状态，便于验收角色主页、收藏卡、场景与对话。
5. 如需回到未添加蛋状态，在“我的 → 账号 → 重置本地体验数据”中清除本地演示数据。

## 当前实现边界

- 未接入王敏侧正式服务时，`FUHUAQIAN` / `FUHUAHOU` 仅在内部开发数据空间运行，不写入正式收藏、货币或统计，也不会伪装成正式数据。
- 本目录只保留前端静态页面、H5 与 `services/` 接口 mock，不包含云函数，也不调用 `wx.cloud.*`。
- 露珠、商店、背包和系列收藏卡属于历史 demo 资产，不是普通版发布要求；迁移前只用于独立内部 demo 回归。普通版提审包必须按合规清单移除其页面注册、入口、live 接口和埋点。
- H5 收藏卡把分享图数据回传小程序，由微信相册能力保存；开发者工具里建议同时用真机验证授权流程。

## 用户资料与公开 ID

- 优先使用微信授权返回的昵称、头像、性别和地区；微信没有返回的字段保持空白，不填充演示数据。
- 用户公开 ID 格式为 `EB-注册日期-毫秒时间编码-随机唯一段`，首次注册时生成并持久化，同一注册时刻的用户由随机段区分。
- 正式服务端接入时仍应给公开 ID 建立唯一索引，并在极低概率碰撞时重新生成；前端格式无需改变。

## 校验

在项目根目录运行：

```bash
node scripts/verify-project.js
node scripts/verify-v2.js
node scripts/verify-h5.js
node scripts/verify-v211.js
```

校验会检查页面四件套、JSON、组件引用、工程根目录设置、v2.28 文档职责、普通版发布门禁、首页互动、第一人称文案、服务端时间、收藏卡和 H5 渲染约束。露珠与道具断言仅用于历史 demo 迁移回归。
