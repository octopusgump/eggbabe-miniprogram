# MVP 实现说明

## 产品取舍

压缩包源码中的 `scene-picker`、`scene-live` 与场景图片来自旧版孵化场景方案。最新 PRD 第 6.2 / 6.3 节明确要求孵化期“不展示任何场景，也不提供场景选择入口”，因此这些旧页面未注册到 `app.json`，最终交付包也不包含它们。

## 页面覆盖

- 进入与账号：授权进入、隐私政策、个人信息、设置、账号、注销完整状态。
- 单蛋绑定：空状态、唯一蛋限制、激活码成功反馈、四类异常反馈。
- 孵化：首页蛋形动画、轻触反馈、3 秒长按贴贴、倒计时、进度、每日状态。
- 修炼手册：昵称、贴贴、今日许愿、蛋前教育、彩蛋涂鸦。
- 破壳：预设时间判断、数字确认、唯一收藏卡、保存与分享、卡册。
- 破壳后：宠物档案、每日心情与状态、文字对话。
- 我的：0 / 1 只蛋状态卡、卡册、5 个个人激活码、资料与账号入口。
- 本地完整流程：只接受 `JIHUOMA`，绑定后仍按正常孵化流程进入六个破壳后生活场景。

## 前端验收场景

1. 首次进入：未同意隐私政策时不能继续；同意后可以进入首页。
2. 未添加蛋：首页与“我的”都展示空状态和添加入口。
3. 激活校验：本地输入 `JIHUOMA` 成功，其他内容显示无效提示；正式接入后以服务端错误码为准。
4. 单蛋限制：成功添加后再次输入任意激活码，提示只能绑定一只且激活码未消耗。
5. 孵化动作：首次昵称 / 涂鸦分别增加 20%，当日首次贴贴 / 许愿 / 教育分别增加 5%；重复操作不重复加进度。
6. 双轨规则：进度最多 100%，不提前改变破壳日；未到时间不能生成收藏卡。
7. 破壳闭环：测试将服务器时间推进到预设时刻后，生成的同一张收藏卡可重复查看但不会重新随机。
8. 破壳后：档案、每日状态、卡册和文字对话均使用同一只蛋宝宝的数据。
9. 注销状态：提交后留在“15 天冷静期”状态；重复进入不重复提交；可二次确认取消。
10. 重置：清除本地体验数据后恢复未添加蛋状态。

## 服务端接入点

- `wx.login` 的 code 换取用户身份与 token。
- 激活码的服务端校验、消耗与来源记录。
- 用户—宠物唯一绑定约束和并发幂等。
- 破壳时间、固定随机结果、全局唯一收藏编号。
- 每日状态生成与对话模型接口。
- 分享图只接受服务端基于真实 AppID 生成的小程序码；未配置时禁止导出，不使用占位图案。
- 埋点：激活、首个动作、回访、破壳、保存 / 分享、对话开启。
