## 3. 角色锁定

### 玉兔（Jade Moon Rabbit）

- 奶油白 bouclé 绒线质感、蛋形一体身体、两只高耳；左耳直立、右耳略向外放松，耳内为钴蓝刺绣线。
- **脸部硬约束**：两只大、圆、琥珀黄玻璃穹顶眼，低位、宽间距、严格对称；每只眼左上有小白高光；小 Y 形鼻；每侧恰好三根钴蓝刺绣胡须。禁止小眼、棕眼、上移眼、斗鸡眼、额外眼、缺胡须、通用兔脸。
- 短小自然前爪和椭圆脚，始终贴地且有正确接触阴影；无衣服、无真人式四肢、无悬浮。

### 锦鲤（Boon Koi）

- 奶油白圆润锦鲤身体，鱼鳞浮雕、橙棕／琥珀色耳鳍、尾鳍、圆玻璃眼、简洁笑脸、黄色雨靴；身体必须是鱼，不能长正常人手臂。
- **尺度硬约束**：以本文件列出的两张通过场景图为房间内尺度锚点；身体厚度和整体占比必须保持一致。角色不得因站立、画画、阅读、游戏、泡茶或听音乐而放大；不得遮挡床、书架、台灯、窗户主体或右桌。
- **面部硬约束**：眼球数量、穹顶大小、左右间距、瞳孔位置、高光、笑线长度和位置必须逐项匹配审核角色图；禁止斗鸡眼、斜视、大小眼、眼球外翻、额外眉鼻嘴、双重笑线或脸部挤压。闭眼只把原眼替换成两条简洁对称弧线，其他脸部比例不变。
- **单角色硬约束**：画面只允许一名锦鲤。禁止生成玉兔或任何第二角色；不得把被面图案、纸上草图或房间装饰变成立体兔子、兔子玩偶或角色。
- 画画与游戏：使用**淡青蓝色半透明灵魂手**操控画笔／手柄；双手漂浮于鱼鳍前方、连接感自然，不换成实体人手。
- 阅读：如需托书，用淡青蓝色灵魂手托住书；书本必须清晰位于鞋子和身体上方，不穿模、不卡进黄色靴子。
- **灵魂手根部硬约束**：从指尖到根部均须为一致的淡青蓝半透明发光材质，根部以柔和透明渐变自然消失。不得生成白色或乳白色实体腕口、袖口、截断圆面、连接块、骨头状结构或与鱼身相连的白色短臂。

- 游戏：必须出现清晰、完整、方向正确的掌机或双摇杆游戏手柄，恰好两只灵魂手真实握住控制器；不能空手假装游戏，不能用房间中的木块、纸笔或杯子替代。

| 白天 | 窗外自然日光是唯一主光；台灯可见但关闭。投影由窗户方向统一决定。 |
| 落日 | 温暖低角度橙金色日光；台灯可开启，作为较弱暖色补光。 |
| 夜晚 | 冷月光／城市夜光为窗外环境光；台灯开启，形成合理暖冷对比。 |

### 季节窗口范围

| 季节 | 本窗口应覆盖的环境键 |
| --- | --- |
| 春 | `spring_clear_{day,sunset,night}`、`spring_cloudy_{day,sunset,night}`、`spring_rain_{day,sunset,night}` |
| 夏 | `summer_clear_{day,sunset,night}`、`summer_cloudy_{day,sunset,night}`、`summer_storm_{day,sunset,night}` |
| 秋 | `autumn_clear_{day,sunset,night}`、`autumn_rain_{day,sunset,night}` |
| 冬 | `winter_clear_{day,sunset,night}`、`winter_cloudy_{day,sunset,night}`、`winter_snow_{day,sunset,night}`、`winter_post_snow_{day,sunset,night}` |

天气只能通过窗外景色、天光、地面湿润／雪景、玻璃雨痕和室内色温表现；不可更换房间或在室内引入不合理的雨雪。

## 5. 批次与人工审核

1. 每个窗口每次生成 4–30 张**独立**图片；建议先 4–9 张验证一个环境或动作组，再扩大批次。
2. 人工审核通过前，后续窗口不得把该输出当作新的角色参考图。
3. 审核逐项检查：脸部身份、耳／鳍／手规则、厚冬被与台灯、家具完整性、光源／影子、动作与道具穿模、天气可读性、横版构图和尺寸。凡有灵魂手的图，必须额外放大检查两只手的根部：淡青蓝半透明材质应连续至自然渐隐处，不得有白色／乳白色腕口、截断面、袖口或连接块；任一只出现即判不通过并单张重做。
4. 不通过：只重做失败的单张或同一问题的小批，不扩大到全季节／全角色。
5. **锦鲤新增否决门槛**：生成后先与两张通过场景图并排检查尺度与构图，再与锦鲤审核角色图检查清醒正脸。出现角色变形、面部漂移、尺寸过大、实体玉兔／第二角色、动作道具缺失、错误灵魂手（包括根部发白、乳白截断或实体袖口）中的任一项，立即判定不通过，不保存为候选、不用于后续参考。
6. 在锦鲤连续获得 4 张人工通过图以前，每批最多生成 4 张；不得再次直接扩展到 16 张或更大批次。
