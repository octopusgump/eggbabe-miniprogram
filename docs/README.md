# 蛋宝宝文档入口

先读 [主 PRD 索引](主PRD/00_需求文档索引.md)，再进入所属模块。`docs` 顶层只保留本入口。

| 文件夹 | 用途 |
|---|---|
| [主PRD](主PRD/) | 01 全产品、02 IAA陪伴、03 聊天、04 今日心情；统一编号与版本命名 |
| [技术交接](技术交接/) | 接口、适配器与协作规则；每份注明所属 PRD |
| [设计素材](设计素材/) | 设计规范、美术制作与素材索引；素材原文件名保留 |
| [验收审核](验收审核/) | 验收清单、独立审核及整理记录；候选稿不等于批准 |
| [未来储备](未来储备/) | 未交付方向与待确认事项，不自动进入当前排期 |
| [历史归档](历史归档/) | 被替代方案、原始决定与旧实现，保留追溯，不作为执行入口 |
