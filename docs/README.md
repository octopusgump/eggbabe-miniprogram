主 PRD 与 Design 当前保留“空房 + 第一人称去向／状态说明”；《今日心情飞书稿》提出只显示通用“外出中”、不透露地点或活动。两者尚未形成统一产品结论。确认前不得仅凭任一候选文档改写外出文案、入口或服务端合同；已确认且不冲突的边界仍是外出只使用 3 张空房全景、不能聊天或触发角色动作，正常导航与设置不受影响。

## 6. 维护规则

1. 产品决策先更新主 PRD，再同步 Design、实现口径、测试门禁和代码。
2. 当前文档只能引用本仓库 `docs/` 内路径，不再新增 `../PRD归档/` 依赖。
3. 历史文档不删除，但必须明确标注为历史或储备。
4. 图片生产说明不进入产品基线；正式资产只有在运行时配置登记并通过验证后才算上线内容。
