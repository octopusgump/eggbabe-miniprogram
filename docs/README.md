## 维护方式

最新决定先进入所属模块 PRD，再同步 Design、实现合同和验收；只维护一处当前规则正文。历史保留独有原文，重复载体在完整整合并修复引用后可删除。文档状态必须区分确认、前端实现、人工验收与发布。
