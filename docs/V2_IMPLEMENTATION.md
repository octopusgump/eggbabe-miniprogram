# V2 增量实现说明

本版本基于现有 23 页 MVP 增量升级，没有恢复已删除的“我的”页角色模块，也没有改变角色主图和“更换场景”的既有交互。

## 已落地

- `live/demo` 独立运行上下文；展会玉兔不再覆盖正式宠物数据。
- 统一北京时间服务；配置云环境后从 `serverTime` 云函数校准。
- 统一埋点入口和 V2 通用属性，未联网事件保留本地队列。
- 本地写入失败返回错误，并产生 `data_write_fail` 事件。
- 六场景采用“通用页面引擎 + 角色场景组 + 冻结套装卡池配置”。
- 场景互动低概率掉卡，每日上限 2 张；展会模式第二次互动起保证首张卡，便于短时体验。
- 卡册拆分为“破壳卡 / 收藏套卡”；`YT-S01` 固定显示 10 个 checklist 卡位，重复副本折叠且不重复计算完成度。
- 第一季接入 10 张玉兔水彩 Hero，小程序使用约 120KB 的轻量 WebP 预览，H5 保留原始 JPG。
- 抽卡揭晓显示 `YT-S01`、清单编号和唯一副本编号，不显示 COMMON / RARE / SSR。
- 正式云端掉落通过事务内的每日发行计数器生成 `EGG-YT-YYYYMMDD-XXXXXX` 唯一编号。
- 聊天回复开始使用今日心情和角色 MBTI 上下文。
- 提供微信云开发函数骨架：登录初始化、服务器时间、激活码事务核销、场景卡服务器掉落、埋点上报。

## 云环境启用

1. 在微信开发者工具开通云开发，并创建数据库集合与索引，结构见 `V2_DATA_MODEL.md`。
2. 上传并部署 `cloudfunctions/` 下各云函数，同时安装云端依赖。
3. 在 `miniprogram/config/v2.js` 填写云环境 ID，将 `cloudEnabled` 改为 `true`。
4. 生产发布前关闭 `localPreviewFallback`，激活码、时间、卡片掉落和正式写入只接受云端结果。
5. `YT-S01` 使用随云函数部署的冻结卡池，数据库运营配置不得覆盖卡名、清单号、Hero 或 `BASE` treatment。

## 尚需外部配置

- 云环境 ID、集合权限和唯一索引。
- 正式激活码；`YT-S01` 已有内置冻结卡池，无需另建数据库卡池。
- 隐私政策 URL、企业微信客服账号、订阅授权视觉资产。
- 锦鲤、企鹅各自的新套装与场景组素材。
