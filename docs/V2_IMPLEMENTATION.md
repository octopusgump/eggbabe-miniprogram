# V2.23 增量实现说明

本版本以 2026-07-19 11:59 的 `docs/蛋宝宝小程序_V2_PRD.md` v2.23 为产品基准，在现有 V2.17 Preview 上增量修改。

## Bohao 侧实现边界

- 本目录只包含微信小程序前端、收藏卡 H5、`services/` 接口封装与本地 mock。
- 不保留 `cloudfunctions/`，不调用 `wx.cloud.*`，不在本目录实现数据库、云函数、管理后台或服务端消息发送。
- 正式模式只接受王敏侧接口返回的 `mode=live` 数据；服务未接入时明确失败，不把本地 mock 冒充正式结果。
- `project.config.json` 的本机/工具配置不由本轮修改。

## 已落地

- WAIC 反馈已并入孵化首页：不展示剩余天数 / 时分，不在孵化期生成每日心情；孵化进度使用右上角百分比圆环并提供轻提示。
- 独立孵化手册入口已下线；首页每天平铺 1–2 个任务，保留愿望、蛋前教育和彩蛋涂鸦的既有子页面。
- 孵化期常驻「跟我说说话」输入框：每日首次 +5%，不改变破壳日；提交后只给身体反应与低频第一人称气泡，不接大模型。
- 绑定后的首次进入与未命名期间每日首次进入显示命名 bottom-sheet，可选择「暂不命名」；改名按北京时间每天最多 1 次。
- 孵化首页使用不可更换的小房间场景，前端完成季节底图、天气粒子与昼夜光线三层表现；不申请定位，位置固定上海。正式天气枚举由 CTO 侧在 bootstrap 数据中提供，缺失时前端降级为晴天。
- 轻点蛋在点击位置显示粒子且不震动；长按每满 1 秒震动一次、最多 3 次，满 3 秒完成贴贴；破壳后角色继续支持长按贴贴。
- 用户可见的蛋宝宝输出已统一改为第一人称「我」对「你」。

- 「我的收藏卡」保持统一连续页面，不使用卡类 tab；身份收藏与收集系列同屏展示。
- `YT-S01` 固定 10 个卡位，未获得显示「尚未遇见 + 007/010」；已遇见的卡不重复出现。
- 场景互动初始遇见概率为约 18%，每日最多 2 张；互动特效结束后再播放光点预示与翻卡揭晓。
- 用户可见文案只用「收藏卡 / 遇见 / 收集」，不显示旧卡类名或「卡池 / 掉落 / 抽卡 / 稀有度」。
- H5 与原生兜底统一显示原型、名字、年月日生日、星座、性别符号、MBTI、性情独白、血型；头像字段仅保留在数据记录中，不再显示于卡面左上角。
- H5 地址尚未部署时，身份收藏卡与已获得的收集系列卡都会打开原生完整卡面；正式 HTTPS 地址配置完成后自动切换到 web-view。
- 已删除旧的公开直达入口、退出恢复逻辑与专用预览页面；本地 `FUHUAQIAN` 按正常 7 天孵化且不预置收集系列卡，`FUHUAHOU` 直接生成已孵化玉兔、身份收藏卡与 10 张可逐张打开的收集系列卡，仅用于内部验收。
- 卡册只展示当前已孵化宠物实际拥有的收集系列卡；重置本地体验会同时清除宠物、收集系列卡、每日计数与完成记录，避免旧会话孤立卡阻断详情页。
- 插画区域固定 4:5、铺满展示；卡面无黑色卡框，标题无装饰星星和 `eggbabe` 小字，系列编号位于标题右侧。
- H5 不计算星座、不生成名字、不选择插画，也不生成任何随机业务值；所有字段来自已定稿 JSON。
- 三套 OFL 字体均已转换成本地 WOFF2，不依赖 Google CDN：收藏卡名字与性情独白优先 ZCOOL KuaiLe，英文/数字使用 Google Sans，中文正文优先 PingFang SC，设备缺失时按需加载 Noto Sans SC。H5 动态子集同时包含名字与独白；原生回退通过 WXSS 内嵌全部固定独白的轻量 TTF，保存图绘制同字体预渲染的 2x 透明素材，并在小程序包内携带 OFL 1.1 许可证。部署与许可证规则见 `h5/birth-card/assets/fonts/README.md`。
- 分享长图包含完整卡面、全局编号、真实小程序码与未使用的个人分享码；H5 通过 `postMessage` 回传图片数据，由小程序调用相册能力保存。
- 破壳承接加入预设时间前 2 小时容差；正式业务判定必须先取得服务端北京时间，未取得时不再回退设备时间。
- 孵化完成度按「实际累计进度 ÷ 周期理论最大进度」归一化，达到 90% 记为完整孵化。
- 锦鲤已登记 6 个专属生活场景、10 张固定收藏卡与轻量小程序预览图；身份收藏卡会使用已有完整锦鲤插画，不再退化为文字占位。
- 对话前端 mock 增加不适宜内容、敏感个人信息与危机表达检测；危机固定回复包含全国统一心理援助热线 12356，且不写入偏好画像。
- 隐私政策补充行为数据与个性化用途；帮助中心补充硬件异常客服路径。
- 增加订阅消息授权封装：绑定成功后可请求破壳日/即将破壳模板；用户拒绝后不重复索取。
- 露珠、商店、背包与装饰道具属于 V2.1；V2.0 已隐藏入口并停止本地发放，相关前端源文件暂保留供下一迭代。
