# V2.11 增量实现说明

本版本基于现有 MVP 增量升级。用户侧卡片统一称为「收藏卡」；文档与代码内部仍可用生成来源区分处理逻辑。

## 已落地

- 「我的收藏卡」改为一个连续页面，不再用卡类 tab；身份收藏与收集系列同屏展示。
- `YT-S01` 固定显示 10 个卡位，未获得显示「尚未遇见 + 007/010」式占位；重复副本折叠，不重复计算完成度。
- 系列内编号与全局唯一编号同时保存在数据中；列表保持简洁，全局编号用于副本明细与分享图脚注。
- 所有用户可见入口统一为「收藏卡 / 我的收藏卡」，旧卡类名称不再出现在界面。
- H5 卡面为 9:16 三段式水彩模板：顶部名字标题、中部 4:5 插画、底部三行数据。插画铺满视口且不显示黑色卡框；卡面只展示名字、MBTI、星座、生日。
- 名字标题动态加载 Google Fonts OFL 版 `ZCOOL KuaiLe`，使用 `text=` 按名字请求子集；失败时回退 PingFang SC。
- 未命名由服务端角色名字池固定生成；名字池与本地 demo 契约保持一致，不再用原型名充当名字。
- 服务端在生成收藏卡时，按节令与 MBTI 标签加权确定 `illustration_id` 和 `illustration_context`；H5 只渲染，不抽取任何随机值。
- 星座按统一边界表计算；空值与非法日期安全返回；H5 使用服务端结果，不重复计算。
- 分享长图包含完整三段式卡面、全局编号与小程序码；任何模式缺少真实小程序码时都拒绝生成假成品。
- 品牌字标统一为小写 `eggbabe`；编号体系继续使用 `EGG-` 前缀。
- 蛋宝宝页增加「商店 / 背包 / 露珠余额」；商品分装扮配件、投喂零食、场景装饰三类，全部为纯装饰与情感反馈。
- demo 模式提供独立露珠体验账本；正式购买、余额扣减、入背包、穿戴/卸下使用云函数事务，客户端不能直接改余额。
- `live/demo` 独立运行上下文；展会数据不进入正式宠物、收藏卡、货币或指标数据。
- live 的破壳、每日状态、掉卡与货币记账增加权威时间门禁；未拿到服务器北京时间时不使用设备时间继续判定。
- 埋点上传时由云函数覆盖 `server_ts`；收藏、场景与货币事件均携带 `mode`。
- 数据模型补齐货币余额、货币流水、商品目录、用户背包、每日获取计数和偏好事件表。
- 六场景继续采用通用页面引擎 + 角色场景组 + 冻结系列卡池；正式掉落与副本编号在服务端事务生成。

## 云环境启用

1. 在微信开发者工具开通云开发，按 `V2_DATA_MODEL.md` 创建集合、唯一约束和索引。
2. 上传并部署 `cloudfunctions/` 下所有云函数；新增函数 `currencyAccount` 也要部署。
3. 将 `cloudfunctions/currencyAccount/item-catalog.seed.json` 导入 `item_catalog` 集合。
4. 在 `miniprogram/config/v2.js` 填写云环境 ID，并将 `cloudEnabled` 改为 `true`。
5. 部署 H5 到已加入小程序业务域名的 HTTPS 地址，填写 `birthCardH5Url`、`birthCardApiBase` 和真实 `miniProgramCodeUrl`。
6. 正式发布前关闭本地预览后门；正式激活、时间、生成、掉落与记账只接受服务端结果。

## 仍需外部配置或素材

- 云环境 ID、集合权限、唯一索引与正式激活码。
- H5 HTTPS 域名、卡片读取 API、微信业务域名与真实小程序码。
- Google Fonts 在目标网络环境的实机可达性；不可达时当前会安全回退 PingFang SC。如需完全离线，应另行托管 OFL 字体子集。
- 锦鲤、企鹅的插画池、标签、系列与场景组素材；当前完整插画池为玉兔 10 张。
- 隐私政策 URL、企业微信客服账号、订阅授权视觉资产。
