# 道具简笔临摹与 v2 本地门槛同批定稿、不接 AI 识图

IAA「一起画」需要减少乱画灌水，同时让部分信件日绑定道具主题（如拨浪鼓）有可展示结果。产品选择：蛋形画布上短暂显示 **line 简笔**（看一看 / 再看一眼），用户每次 v2 达标「画好了」后在画板内展示 **彩色 webp** 并 **+10✦**（新 completionId；同日可多次）；**不**用 50/70/80 相似度分档，**不**接入远程 AI 判「画得像不像」；**进入不花星**（信 / 活动 / 桌面一致）；活动 list CTA 为 **「赚 10✦」**，**不是**「花 20✦」（茶会等活动 20✦ 规则不变）。

**无**信纸「收下」、**无**纪念册道具入册、**无**累计三次达标入册（相对 2026-10-10 旧 §6.4 稿已废止）。规则见主 PRD §6.2 v2、§6.4；前端实现见 PR #50（`feat/draw-together-prop-20261101`）。

**Supersedes** the unmerged「主题画画」draft (60/30/10 random tier stars, square reference canvas, tier celebration copy). That draft is **abolished** on `main`; see PRD §6.5. §7.5.1 画画小回礼 **不**再作为道具临摹发星依据。
