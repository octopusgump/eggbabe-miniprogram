# 蛋宝宝｜陪伴星星光效视觉方案

> 2026-09-22 · COO 评审稿 · 选版后由 Claude Code 实现

## 一、这是什么

陪伴成功时，信件里现有 `✦ +1` 亮起；关闭信件，房间左上角星星回应一下。平时只留很轻的呼吸光。COO 已指定：**图 2 的黄色、图 3 的近旁受光感**，信件内保留 5–8 个光点。此前三版“发光星星加飘光尘”没通过；这次让纸面受光成为主角。

| 位置 | 触发 | 反馈 |
| --- | --- | --- |
| 信件 `✦ +1` | 本次陪伴成功且真的获得星星 | 光效 ≤1.8 秒；一次轻声、一次轻震 |
| 房间左上角星星 | 关闭信件 | 光晕回应 1.2 秒，不重播声震 |
| 左上角常驻 | 平时 | 极轻呼吸，无声无震 |

## 二、项目边界

视觉只用 WXSS 动画和无文字、无点击的装饰 `view`，复用原有奖励状态。**本稿覆盖旧任务书的“不加声音”“不改 `life-scene.js` 逻辑”“不加资源”三条，仅开放一次成功反馈所需的页面 JS 接入、一个本地短音效和必要的音频生命周期处理。**实施前同步修订旧任务书；不改奖励、计数、服务逻辑。

信件正文、“明天呢？”、字号间距及左上角卡片位置、尺寸、内容都不动。不加手、脸、立体星、爱心、星球、文案、纪念册、背景音乐、长震、图片序列、canvas、第三方库；不碰 `services/`、`fixtures/`、`config/`、`app.json`。图里的手和星只用于研究受光。跨信件到房间的连续飞行、真实景深和手部光照也不做——现有界面没有承载它们的空间。

## 三、长什么样

**A｜芯光先醒：**星附近先亮，纸面一小块暖光跟上；7 个细点错时短距离上浮，先于光消失。回房间时亮得短、收得近。

![方案 A：芯光先醒](./assets/companion-star-a-20260922.png)

**B｜环境先亮：**纸面先泛起暖黄，再托亮星；7 个点只在近处上浮。回房间留下稍宽、稍低亮的余光。**B 更接近 COO 指出的图 3。**

![方案 B：环境先亮](./assets/companion-star-b-20260922.png)

两图是放大示意，不改变原有文字、间距和卡片比例，也不作为小程序图片加载。

## 四、共用规则

- 主光 `#FFDD79`，过渡 `#F7CC6E`，近旁反光 `#F3BB5A`；原信件字色 `#9A782C`、房间星色 `#D1A73F` 不改。浅信纸上只叠局部低透明度光，避免整张变黄。
- 信件标称 7 点（可在 5–8 内微调），错时上浮、不排圆环；回房间可有 2–3 个更弱的点，限卡片内。这是两个时机，**不能加总成一次爆出 9–11 个点**。
- 信件 `✦ +1` 是同一文本节点。若文字缩放只能整行短暂缩放；若 `+1` 跟着缩放不合适，就只缩放装饰光核、原字保持 1.0 倍。不能写成“单独放大现有 `✦`”。
- 仅成功且 `awardedStars > 0` 时播一次；失败、同日重开、回房间和常驻都不重复。沿用 `reducedMotion` 取消动画和震动，保留 `✦ +1`；声音遵循系统静音，失败也不阻断奖励。

## 五、A/B 动作与声音

| 版本 | 信件 | 回房间 / 常驻 | 光域与点 |
| --- | --- | --- | --- |
| A | 先芯光，`0.3 s` 达峰，`1.6 s` 完全结束；整行峰值 1.04 倍。 | 回房间 `0.2 s` 达峰、`1.2 s` 静止；常驻每 3.6 秒呼吸一次，透明度 `.06–.18`。 | 光域宽 2.0 倍星字、透明度 `0–.22`；点 `3–5 rpx`、透明度 `0–.42`，上浮 0.4–0.8 倍星宽。 |
| B | 先纸面受光，`0.5 s` 达峰，`1.7 s` 完全结束；整行峰值 1.03 倍。 | 回房间 `0.3 s` 达峰、`1.2 s` 静止；常驻每 3.8 秒呼吸一次，透明度 `.05–.16`。 | 光域宽 2.8 倍星字、透明度 `0–.18`；点 `2–4 rpx`、透明度 `0–.35`，上浮 0.5–1.0 倍星宽。 |

两版的房间星本体都不位移、不放大；常驻只改光晕透明度，摆幅 `.12/.11`，低于旧要求的 `.25`。完整 0.1 秒分段和亮度曲线在附录。

**两版共用声震：**奖励成功后 `0.0–0.45 s` 播放一次柔和的上行大三度双音，第二音更轻，尾部淡出；初始播放音量 `0.20`（0–1），由 COO 真机试听定最终听感。不要《塞尔达》原声旋律、提示音三连或音乐段落。`0.2 s` 第二音到达时仅一记轻短震；不支持轻档或调用失败就无震，不升级中/重档、不补播。系统静音时不强制外放。

## 六、数量与职责

当前交付 **1 份文档 + 2 张评审图**，评审图不进小程序。选版后预计改 **2 个 WXSS、2 个 WXML、1 个页面 JS，新增 1 个本地短音效**；不新增页面、接口或奖励状态。COO 选版并在真机上验收；Claude Code 实现并跑旧任务书列出的检查。文档通过不等于效果已上线。

## 七、验收

1. [ ] 陪伴成功才出现原位 `✦ +1`、局部受光和 5–8 点；1.8 秒内结束，不挡点击。
2. [ ] 同一成功只响一次 ≤0.45 秒轻双音、轻震一次；失败、重开、回房间不重复。
3. [ ] 静音不强制出声；无轻震能力时无震正常；减少动态效果时无动画与震动，奖励字仍在。
4. [ ] 关闭信件左上角原 `+1` 同时出现，星星 1.2 秒内回到常驻光；没有跨屏飞行。
5. [ ] 常驻几乎不被注意；信件文字间距和卡片内容、尺寸、位置与此前完全相同。
6. [ ] iOS、Android 真机听感、触感与小屏显示通过；不以开发者工具模拟器代替 COO 人工验收。
