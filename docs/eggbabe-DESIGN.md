## 1. 设计原则

1. **一个页面只有一个视觉焦点。** 场景页以角色与空间为主，回忆详情以物件或明信片为主，工具和说明退到次级。
2. **界面服务于陪伴叙事。** 使用安静、温暖、可触摸的 2.5D 空间；避免通用 SaaS 卡片墙、游戏化图鉴和奖励话术。
3. **用固定映射代替猜测。** 角色、状态、季节、天气或时段没有匹配素材时，显示明确状态，不复用错误图片。
4. **图片承载场景，原生 UI 承载信息。** 标题、日期、正文、按钮和状态不得烘焙进场景图。
5. **正式资源与候选资源分离。** `_candidates/`、参考合成图和实验文件不能进入正式运行时配置。

## 3. 视觉基础

### 3.1 运行时颜色

| 用途 | 色值 |
| --- | --- |
| 主交互、主按钮 | `#002900` |
| 主按钮按下 | `#001A00` |
| 一级文字 | `#1A1A1A` |
| 二级文字 | `#5C5C5C` |
| 三级文字 | `#8C8C88` |
| 页面底色 | `#FAFAF8` |
| 卡片底色 | `#FFFFFF` |
| 分隔线 | `#E5E3DF` |
| 品牌绿／黄／粉 | `#9DB65B` / `#EDE78E` / `#F4B9AE` |
| 回忆底色／文字 | `#FFF6F5` / `#80625D` |
| 错误色／底色 | `#D9463C` / `#FDECEA` |

不要在页面中新增近似色。需要新语义色时，先补充全局对照，再使用。

### 3.2 字体与尺寸

- 中文使用 `PingFang SC, Helvetica Neue, Microsoft YaHei, sans-serif`。
- 字重最高为 `600`；不使用伪粗体 `700`。
- 设计稿基于 375px 宽度，换算规则为 `1px = 2rpx`。
- 正文优先 `24–30rpx`，辅助文字不小于 `20rpx`；标题靠字号与留白建立层级。

### 3.3 形状与交互

- 单个紧凑操作使用 `112rpx × 112rpx` 圆形。
- 两个及以上同组操作使用一个胶囊容器，每段 `112rpx`。
- 文字主按钮使用 `96rpx` 高胶囊。
- 卡片、输入框和底部面板可以使用中大圆角；紧凑按钮不使用中圆角矩形。
- 常规按压为 `160–180ms`、`scale(.98)`；回忆卡高光最多 `400ms`。
- 系统开启“减少动态效果”时，移除位移、旋转和循环动画，保留静态状态反馈。

## 4. 核心体验

### 4.1 破壳前首页

- 首页是一张全屏孵化房间，不是卡片式仪表盘。
- 季节、天气和日间状态由稳定规则决定；正式版不提供手动场景切换。
- 许愿、早教、画蛋壳组成一个三段胶囊操作组；锁定态使用明确的灰阶图标和遮罩，不通过整体降透明度糊掉内容。
- 蛋的触摸、倾听和光影反馈保持轻微；强动画只留给破壳等情绪高潮。
- 破壳后的命名使用底部面板，保留场景上下文并适配底部安全区。

### 4.2 破壳后生活空间

- 使用一张 `2823 × 1672` 的三屏连续全景：左侧起居区、中间桌面、右侧布置区。
- 进入时直接定位到 ta 所在屏；用户可以横向查看其余空房间，不从错误屏播放滑入动画。
- 场景切换先预加载，成功后交叉淡化；加载失败保留旧场景并给出重试。
- 大状态只有家、旅行、打工、上学。ta 外出时仍显示空着的家和第一人称去向文字，不把目的地图片放进实时生活空间。
- 每个居家小状态只提供一个固定动作，并始终可进入完整对话页；外出时不提供对话、写信、留言或回信入口。
- 左下角角色对话按钮只在居家时显示，点击直接打开完整对话页。外出时左下角留空，不显示信封。
- 发送消息后，消息流立即滚到左侧“正在回复”气泡；三个圆点按 `0.5s` 完整循环依次轻微上浮和变亮。回复或失败后立即移除；减少动态效果模式显示静态三点。
- 居家业务状态固定为睡觉、小憩、发呆、涂涂画画、看书、打游戏、听音乐、看窗外 8 种；小憩沿用内部键 `lazy`，睡觉沿用内部键 `sleep`，两者必须使用独立动作图且不得重复计数；动作图是否已交付不改变业务状态集合。
- V3.6 / V3.7 右下角只显示“我的／设置”图标，点击直接进入“我的”，不出现百宝箱弹层。收藏卡、明信片、纪念物与旅途回放保留代码和图片，但 trial / release 无入口、无未读红点，旧路径转回“我的”；develop 可继续验收。

### 4.3 角色动作全景

- 正式动作图是已经烘焙角色、道具、遮挡、接触阴影和环境光的完整全景；运行时不得再次叠加透明角色或道具。
- 只有角色、居家状态、动作状态和环境键全部匹配时才显示动作全景；否则回到同环境的空房全景。
- 当前已登记的通用动作资产子集为睡觉、看书、打游戏、看窗外、画画、听音乐；每张图片只用于其实际烘焙的环境键，未交付的业务状态或环境组合显示同环境空房全景。
- 特殊天气只使用已明确登记的版本：玉兔春季阴天秋雨日落看书；锦鲤夏季暴雨夜睡觉、冬季雪天看窗外。
- 玉兔夜间完成关灯后可以切换闭眼关灯版本；锦鲤没有对应资产时不得复用玉兔版本。
- 动作全景为大图 CDN 资源，不进入小程序主包。

### 4.4 蛋壳绘画

- 蛋壳画布占页面主要面积，默认约 `89vw`；底部工具条和右侧撤销／清空不能遮住主要绘制区。
- 支持双指缩放；绘制坐标必须随缩放反向映射，确保笔迹不漂移。
- 画笔提供五种颜色、五档粗细，默认 `5px`；每一笔保存自己的颜色。
- 橡皮擦可以连续擦除笔迹与贴纸；撤销、清空和“撤销清空”使用同一历史状态。
- 停止绘制约 `700ms` 后自动保存；导航栏持续显示保存中、已保存或未保存状态。
- 撤销和清空的禁用态使用专用置灰图，不降低整个按钮或标签的透明度。

### 4.5 回忆、收藏卡与明信片

- 本节保留后续版本的内容与视觉规格，不属于 V3.6 / V3.7 正式用户界面；恢复前必须由产品负责人重新放行。
- develop 环境可直接验收纪念物、明信片、收藏卡和旅途回放页面；trial / release 不展示入口并由页面级门禁阻止旧路径访问。
- 纪念物只显示真实出现的物件，使用三列缩略图；不显示锁定格、总数、稀有度或完成度。
- 纪念物详情以单件主图为首屏焦点，下方使用桃粉色“我还记得”第一人称回忆区。
- 明信片列表只显示封面、标题和日期。同一次旅行按 `journey_id` 聚合为一个入口。
- 点击明信片大图进入独立全屏旅途回放；回放只浏览历史图片，不改变 ta 当前状态。
- 回放不显示假的滑动胶囊、`1/N` 进度或收集提示；加载和错误状态必须始终可返回。
- 今日收藏卡只推荐一张真实收藏卡，不改造成多卡图鉴。

## 5. 图片与资产门禁

| 资产 | 正式规格 | 关键限制 |
| --- | --- | --- |
| 破壳前三屏中央场景 | `941 × 1672` WebP | 与环境 key 精确匹配 |
| 破壳后三屏全景／动作全景 | `2823 × 1672` 不透明 WebP | 固定镜头；角色与动作同图烘焙 |
| 旅行明信片 | `1600 × 900`、16:9、不透明 WebP | 不拉伸；无文字、Logo、UI 或水印 |
| 纪念物 | 透明单件图 | 只显示已登记的明确 ID |

- 大型环境图和动作图通过 `environment_cdn_base` 加载。
- 正式运行时路径只在配置文件中登记；页面不得自行拼接候选路径。
- 缺图时显示加载失败或空态，不用其他天气、角色、目的地或第三方图片兜底。
- 发布前检查上传清单，确保候选、参考源图和实验目录不进入 trial／release。

## 6. 通用状态与无障碍

- 所有网络或大图页面都要有加载、失败、重试和可返回状态。
- 顶部导航、底部操作和全屏回放适配横竖屏安全区。
- 图形按钮提供可读的 `aria-label`；纯装饰层不参与语义树。
- 开发验收器只在 `localDemoEnabled` 下显示，不进入 trial／release，也不修改 live 数据。
- 状态切换不显示倒计时、完成率或诱导回访文案。

## 8. 更新本文的规则

只在以下情况更新：新增跨页面设计规则、修改正式交互、晋级正式资产类型、或现有实现与本文冲突。单张图片替换、测试夹具、候选 Prompt、文件清单和代码实现细节写入各自专项文档，不追加到这里。
