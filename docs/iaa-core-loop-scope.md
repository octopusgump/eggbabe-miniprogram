## 真实入口

- 左上角只显示星星余额与“一起 X 天”，不显示心情，不打开陪伴。
- 左下角是信封，在家与外出都可读信，取消“陪伴 / 聊天”分栏。每日首次进入房间只在圆按钮内播放约一秒纸飞机转信封，配一声轻短“嗖”声，等待主动点击读信，不自动展开信纸。
- 点击“明天呢”后，在家时角色从信纸右下约一秒上移淡入，停住不循环；点击角色进入完整聊天。外出仅展开文字、不显示聊天角色。角色按用户原型选玉兔或锦鲤，无用户切换入口。
- 展开信纸清红点；同日重开/聊天返回保留明日内容且不重播角色，下一日重置。动画期间点击立即执行，不等待结束。已读、到信次数和展开偏好保存在本机，不证明跨设备同步。
- 陪伴正文和奖励不进入聊天历史；聊天仍使用完整聊天页与原有权限判断，外出不绕过聊天门禁。
- 右下齿轮保留。上方新增百宝箱，打开小弹层，第一项纪念册；不擅自加入未确认功能图标。

## 画画与收录

在家点击“一起画”复用孵化前画画布局与工具。陪伴模式只用运行内草稿，不修改原有蛋壳、不提交孵化修炼、不写服务端。画画页面 Canvas 成功准备完成后才领取当天基础星；导航失败或画纸准备失败不发星。至少实际动笔后点“画好了”，导出作品并返回信纸，领取当天首次画画完成奖励，并计有效陪伴一天。完成奖励与开始奖励同额、分别每日一次；开始奖励与收纸条等普通动作共用基础额度。同日可继续画和收录，不重复奖励或计日。中途退出无确认弹窗，保留开始奖励及本次运行草稿；关闭小程序后的草稿恢复暂不做。

作品与一句回应出现在信纸里，完成奖励在上方短暂播放；不新增奖励弹窗、不自动展开明日内容。点“收下”入册，回房间。首次收录引导打开百宝箱。纪念册从真实房间入口只展示本次运行收下的作品；已有样例数据仅保留开发验收入口，不冒充用户收藏。可打开详情、放大与保存图片。

## 星星规则

| 累计有效陪伴日数 | 每日基础星星 |
| ---: | ---: |
| 1–2 | 10 |
| 3–6 | 11 |
| 7–13 | 12 |
| 14–20 | 13 |
| 21–29 | 14 |
| 30–44 | 15 |
| 45–59 | 16 |
| 60–89 | 17 |
| 90+ | 18 |

当天按本日完成后对应的档位固定收益基数，动作先后不影响金额；普通有效动作已经计入当日时不再次提前升档。画好或完成普通有效动作才增加陪伴日数，每日最多一次。缺席不清零、不补算；同日旧快照不重复领星。跨日继续旧草稿不自动领取新一天基础奖励，完成时领取完成当天的完成奖励；之后主动进入新画作才可领取尚未领取的当天基础奖励。完成作品 ID 在本次运行内去重，避免旧回调跨日重复结算。

收星短音效和轻震各一次，信纸完成反馈保留四颗装饰小星；减少动态效果时不播放位移或震动。关闭信纸不再次播放得星效果。音效遵守系统静音；项目目前没有独立声音开关，不新增设置入口。首七个有效陪伴日基础收入 76 星，每日都画好则最多 152 星；茶会 20、旅行 40 保持不变。

## 茶会与后续机制

- 茶会已接通纪念册活动入口：首次免费、后续20星，选清茶/花茶后给对应回应，第二次确认完成并结算，保证现有窗边照片，收下入册；退出保留运行内进度，照片加载失败不结算。旅行40星仍只显示详情；答题、旅行等待与补偿尚未实现。
- 照片兑换品与价格、随机概率、个性化记忆、明日挂画、带小程序码的分享图尚未实现。
- 星星、陪伴日数和作品是本次运行内状态，退出小程序会重置；作品图片为本次生成的临时路径。真实持久化、跨设备幂等由 CTO 后续实现。
- 当前画布仍沿用用户要求的孵化前蛋壳造型；若改成普通画纸，需要另行确认。

## 验收

从破壳后房间开始，核对按钮内到信、主动读信、关闭重开、在家/外出、聊天权限、画画进入奖励、完成返回奖励、跨日草稿、同日继续画、收下入册与齿轮/百宝箱的完整路径。自动检查不能替代 COO 对位置、遮挡、字号、音效、轻震和真机 Canvas 的确认。
