# IAA 陪伴星星与纪念解锁｜开发验收说明

陪伴星星不再使用独立页面。前端静态演示入口收进破壳后房间左上角，与“今日心情”共用同一个状态卡片；不接云函数、数据库、账号、远程 AI 或正式接口。

在四项验收台点击“陪伴星星”，会直接进入 `pages/life-scene/life-scene`。左上角默认显示星星数量和今日状态，展开“今日心情”卡片后显示距离下一段纪念的进度。

本地 fixture 覆盖：

- `AVAILABLE`：首次有效互动演示 `+1`，当前 fixture 从 2 星达到 3 星并解锁纪念；
- `CLAIMED`：重复互动只给陪伴反馈，不重复增加；
- `UNLOCKED`：检查房间状态卡中的纪念达成文案；
- `ERROR`：互动失败后保留当前余额，用户主动重试成功后才演示 `+1`。

房间页只通过 `miniprogram/services/iaa-star-unlock-adapter.js` 消费 `iaa-mvp-v1` 视图模型。当前跨页变化只保存在本次小程序运行内存中。正式的每日幂等、服务端时间、星星写入、跨设备同步和纪念解锁判定均由 CTO 后续实现；本地 fixture 不证明这些能力已经上线。
