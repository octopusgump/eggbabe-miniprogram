# 陪伴星星｜实现与验收说明

陪伴星星是每日陪伴主循环的第二段，是陪伴记录的视觉表达。它不使用独立页面，收进破壳后房间左上角，与“今日心情”共用同一个状态卡片；在 `develop`、`trial`、`release` 中一致显示。不接云函数、数据库、账号、远程 AI 或正式接口。

## 当前星星显示（本次发布）

- 房间左上角显示星星数量和今日状态（“今日待收下 / 今日已收下”）。
- 在信件内完成有效陪伴后，信件显示本次 `+1`；关闭信件后房间左上角立即显示 `+1`。
- 同日重复互动只给陪伴反馈，不重复增加。
- 星星只在本次小程序运行内存中累计，不写入本地存储或远程。
- 极简纪念册已暂停：房间不显示纪念进度，也不显示“纪念已解锁”“已经留下”等没有真实可进入结果的文案。fixture 中的 `nextMemory`、`newlyUnlockedMemory` 字段只保留合同形状，房间不渲染。

## 未来服务端累计（交给 CTO）

正式的每日幂等、服务端时间、星星写入、跨设备同步、持久累计和纪念解锁判定均由 CTO 后续实现；本地 fixture 和页面内防重复点击不证明这些能力已经上线。房间页只通过 `miniprogram/services/iaa-star-unlock-adapter.js` 消费 `iaa-mvp-v1` 视图模型，正式接入时替换 adapter 即可。

## 开发状态 fixture（仅 `develop`）

本地 fixture 覆盖：

- `AVAILABLE`：首次有效互动演示 `+1`，当前 fixture 从 2 星到 3 星；
- `CLAIMED`：重复互动只给陪伴反馈，不重复增加；
- `UNLOCKED`：合同形状保留，房间不展示纪念达成文案；
- `ERROR`：互动失败后保留当前余额，用户主动重试成功后才演示 `+1`。
