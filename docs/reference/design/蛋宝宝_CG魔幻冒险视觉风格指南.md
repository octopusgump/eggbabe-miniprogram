# 蛋宝宝 CG 魔幻冒险视觉风格指南

> **文档层级：美术参考。** 本文只定义视觉语言，不新增产品功能、入口或上线范围；与 `docs/蛋宝宝小程序_V3_6_PRD.md` 或 `docs/eggbabe-DESIGN.md` 冲突时，以主 PRD 和 Design 为准。

> 版本：v1.0
> 适用：蛋宝宝小程序、官网、活动页、社媒内容、KV 与 AI 绘图
> 视觉基准：玉兔与锦鲤现有场景图（沙漠骑行、泳池漂浮、溪流跃起）

## 1. 一句话定义

**蛋宝宝的世界是“可触摸的绒感角色，误入一片温柔又辽阔的魔幻自然”。**

它具有轻度开放世界冒险游戏的空间感：有远方、有天气、有光、有可被发现的小事；但情绪始终柔软、童真、安静。它不是写实荒野、不是硬核游戏，也不是高糖玩具广告。

可以把风格浓缩为：

`毛绒 CG × 童话自然 × 电影级光影 × 轻冒险叙事 × 克制的魔法感`

## 2. 核心气质与边界

| 需要传达 | 画面如何做到 | 不要变成 |
| --- | --- | --- |
| 陪伴感 | 角色有重量、触感、呼吸和细小情绪 | 宠物养成游戏的任务感 |
| 冒险感 | 广阔环境、远景地标、正在发生的行动 | 打怪、战斗、竞技或末日荒野 |
| 魔幻感 | 不合常理但可爱的组合、光与自然的小奇迹 | 复杂法阵、强粒子、玄幻特效 |
| 收藏感 | 材质、配饰、色彩与身份道具可辨识 | 潮玩商品白底陈列 |
| 治愈感 | 柔和色温、留白、低频动势 | 过曝糖水、幼态堆砌或表情包感 |

### 风格守则

1. **角色先于奇观。** 任何场景先让人看到蛋宝宝正在经历什么，再让人看见环境多漂亮。
2. **质感先于装饰。** 毛绒、编织、皮革、橡胶靴、湿润石头与水面，是可信度的来源；不靠堆叠贴纸、描边或滤镜。
3. **魔法藏在自然里。** 用水波、尘雾、夕阳、微光、风和小生物暗示奇遇，不用大面积发光符号。
4. **一张图只讲一个瞬间。** 漂浮、跃起、骑行、看云、发现一朵花——一个清晰动作胜过多个热闹元素。
5. **“类开放世界”只借空间和心境，不复刻任何现成游戏的角色、UI、图标、武器、地标或叙事。**

## 3. 从基准图提炼出的视觉 DNA

### 3.1 角色：软、圆、真有重量

- 主体是带短绒颗粒感的毛绒玩偶 CG，不是光滑塑料，也不是二维卡通。
- 轮廓用大圆形、短肢体、少量五官表达；眼睛高光干净，表情简单但有明确情绪。
- 角色必须与环境发生物理关系：脚踩地、身体压水、尾巴带水花、骑行时有牵引与颠簸感。
- 配件是“故事开关”：黄雨靴、小黄鸭、护目镜、头盔、鱼鳍、钓竿、背包。每张图保留 1–3 个重点配件。

### 3.2 世界：真实自然的尺度，童话世界的逻辑

- 场景是可进入的自然空间：沙漠、森林溪流、清澈泳池、草坡、海岸、雨后城市屋顶等。
- 使用前、中、后景建立纵深。远景可以是山、树林、沙丘、巨石、天空；中景服务角色；前景用草、石头、水面、仙人掌或叶片制造临场感。
- 允许温柔的尺度错位：一只大锦鲤像坐骑、一只小黄鸭像旅伴、一片水面像天空。但它们应当服务角色关系，而非炫技。
- 每个场景至少留一处“探索锚点”：远方地标、可互动的小物件、隐约的小生物或一束特别的光。

### 3.3 光：像电影，不能像棚拍

- 首选低角度自然光：清晨、黄昏、林间漏光、水面反射。让光有方向，阴影有软硬层次。
- 明亮场景保持空气感，暗色场景仍保留温暖的角色可读性；脸部与故事配件不落入死黑。
- 逆光时可出现柔和轮廓光、浅雾和漂浮尘点，但不能白边过重或出现舞台追光。
- 魔幻光源只作局部点睛：水面闪点、破壳暖白光、萤火般微光；面积通常不超过画面 10%。

### 3.4 色彩：自然底色里的一点“蛋宝宝黄”

主色随场景变化，品牌统一感来自角色的燕麦白、暖棕与标志性明黄，而不是所有页面都铺同一种背景色。

| 色彩角色 | 建议色值 | 使用方式 |
| --- | --- | --- |
| 蛋宝宝燕麦白 | `#EEE3CF` | 角色主体、浅色卡片、柔和底色 |
| 绒感暖棕 | `#A66B3F` | 鱼鳍、皮革、标题强调、场景土色 |
| 蛋宝宝黄 | `#F5C83B` | 雨靴、小黄鸭、主行动按钮、关键状态点 |
| 夕阳沙金 | `#D89A57` | 沙漠、黄昏、温暖渐变 |
| 清澈水青 | `#62CFCB` | 泳池、水域、轻交互反馈 |
| 森林深绿 | `#173E32` | 森林远景、深色文字与沉浸页遮罩 |
| 雾蓝灰 | `#A8C6CF` | 天空、次级背景、信息弱化层 |

配色比例建议：**环境主色 60% / 空气与留白 25% / 角色中性色 10% / 蛋宝宝黄或其他高识别色 5%**。高饱和颜色只用来告诉用户“看这里”或“可以点这里”。

### 3.5 材质：一眼能感到“想摸”

| 对象 | 质感要求 |
| --- | --- |
| 玉兔、锦鲤与蛋宝宝本体 | 短绒、细密纤维、柔软压痕；明暗中仍能读出绒面 |
| 鱼鳍、耳朵、口袋等色块 | 可带布料或针织纹理，避免扁平纯色塑料感 |
| 靴子、小黄鸭、头盔 | 轻微哑光橡胶或搪胶，保留圆润反射 |
| 马鞍、缰绳、背包 | 柔软皮革、缝线、金属扣件；细节真实但不硬派 |
| 水、石、沙、植被 | 有可感知的尺度与湿度；避免“AI 糊状背景” |

## 4. 构图与镜头规则

### 横版：官网 Banner、专题头图、活动 KV

- 推荐 `16:9` 或 `2:1`，角色放在画面中部偏左/偏右，另一侧预留给标题和行动按钮。
- 地平线通常位于画面下 1/3 至中线附近；天空、山体或树冠承担广阔感。
- 角色占画面高度约 35%–60%。当画面有奔跑、跃起等动作，可放大至 65%，但不要裁掉关键配件和接触关系。
- 背景文字可以成为一次性的 KV 手法（如沙漠图中的超大“EGGBABY”），但必须低对比、低存在感，不可压过角色或承担正文信息。

### 竖版：小程序首屏、社媒封面、角色海报

- 推荐 `4:5`、`3:4` 或 `9:16`；人物/角色的视线和动作向画面内侧延伸。
- 顶部留给状态、返回和标题，底部留给操作；不要把核心表情放在系统安全区或按钮下方。
- 可以使用俯拍（泳池漂浮）表现安静陪伴，也可用平视或低机位表现一起出发。每页只选一种明确的镜头情绪。

### 景深与焦点

- 主角五官、主配件和与环境的接触点必须清晰。
- 前景可轻虚，远景可因空气透视而降对比；不要用过强人像虚化让环境失去可探索性。
- 镜头语言优先“在场”，少用超广角变形、荷兰角、快速推进等制造刺激的表达。

## 5. 小程序与官网的统一方法

### 5.1 小程序：像一扇能推开的窗

小程序以陪伴和轻互动为主，视觉应该让用户感到“它就在这里”，而不是“我正在闯关”。

- 首页主视觉使用一张完整场景图；文字与数据浮在低透明深色/暖白遮罩上，不切碎成多张花哨卡片。
- 主按钮采用圆润、轻微绒感的暖黄或燕麦白；文字保持高对比，按钮状态变化小而清楚。
- 场景热点仅使用微弱水波、光点或轻位移反馈，并配一条有温度的话；不出现掉落物、经验值、奖励弹窗。
- 动效遵循“有重量、低幅度、低亮度”：呼吸、轻摆、水波、风吹、日光移动皆可；爆炸、强闪、持续飘粒子、夸张弹跳均不可用。
- 信息层级：**角色与场景 → 当下的一句话 → 关键状态/操作 → 次级说明**。任何数值都不应夺走角色的注意力。

### 5.2 官网：像一本正在展开的冒险绘本

- 首屏用一张宽阔叙事 KV，标题不超过两行，副文案只说一个邀请，例如“和蛋宝宝一起，把平常的路走成冒险。”
- 页面滚动可以模拟旅行节奏：远景建立世界 → 近景认识角色 → 小物件讲性格 → 回到行动入口。
- 模块之间使用天空、水、沙、云或纸感留白过渡；不要用科技网格、霓虹渐变或高密度卡片墙。
- 角色介绍、产品说明和活动信息共享同一套材质与色彩，但功能区可以更克制，确保阅读、购买和转化清楚。
- 当官网展示真实产品照片时，可放在燕麦白、沙金或自然场景中；保留一处 CG 场景作为叙事连接，避免商品页与 IP 世界割裂。

### 5.3 通用 UI 语言

| 元素 | 建议 |
| --- | --- |
| 字体 | 中文用圆润、现代、易读的无衬线；标题可加粗，正文常规；不使用尖锐赛博字或复杂手写体作大量正文 |
| 圆角 | 卡片与按钮保持大圆角，建议 16–24px；避免药丸形泛滥 |
| 阴影 | 低对比、偏环境色的软阴影；不使用纯黑硬阴影 |
| 图标 | 圆头、线条简洁、略有手感；与黄靴、鱼鳍、耳朵等圆润语言一致 |
| 蒙层 | 图片上优先使用深绿/暖棕 20%–45% 的渐变蒙层；避免黑色半透明大块遮住场景 |
| 文案 | 观察式、陪伴式、带一点发现感；少用“领取、升级、战力、通关、奖励”等游戏化词汇 |

## 6. 内容选题与场景配方

每次内容创作建议按以下公式组织：

`一个自然地点 + 一个小目标 + 一个伙伴/道具 + 一个物理瞬间 + 一句轻盈情绪`

| 场景主题 | 画面动作 | 道具/细节 | 情绪文案方向 |
| --- | --- | --- | --- |
| 日落沙丘 | 骑着锦鲤穿过风沙 | 黄靴、护目镜、缰绳、远方石柱 | “风把今天吹得很远。” |
| 林间溪流 | 锦鲤从水面跃起，玉兔被溅湿 | 钓竿、卵石、水花、湿叶 | “原来惊喜会从脚边跳出来。” |
| 午后泳池 | 玉兔仰面漂浮，看水面光纹 | 小黄鸭、蜻蜓、小鱼影 | “今天的任务，是慢慢漂一会儿。” |
| 雨后草地 | 角色寻找叶片上的水珠 | 小雨靴、蘑菇、露珠、蜗牛 | “每一颗水珠，都像藏好的小信。” |
| 月下屋顶 | 角色和伙伴看云与远处灯火 | 小毯子、纸飞机、风铃 | “夜晚也会替你把路照亮一点。” |
| 海边清晨 | 角色把一只贝壳放到耳边 | 小桶、海浪、海鸟、潮湿沙面 | “海在讲一个很慢很慢的故事。” |

## 7. 图像生产规范（摄影、3D 与 AI 生成通用）

### 必须包含

- 一个明确可爱的蛋宝宝角色，带可辨认的绒感材质与标志性配件。
- 一个有真实尺度、天气和时间感的自然环境。
- 一个可读的动作或关系：骑、漂、跳、看、找、等、分享。
- 方向明确的自然光和至少一个环境接触细节（压痕、水花、尘土、影子、风）。
- 画面可被裁切到官网横幅和小程序竖版时仍保留主体与留白。

### 必须避免

- 人类主角、写实儿童脸、真人摄影式皮肤。
- 塑料手办感、过度光滑的角色表面、脏乱长毛、恐怖谷眼睛。
- 赛博朋克霓虹、金属机甲、武器、盔甲、怪物、战斗姿态。
- 强烈镜头眩光、烟花粒子、满屏魔法符号、过曝白光。
- 多只角色抢戏、复杂建筑群、难以辨认的背景文字、水印或乱码文字。
- 直接模仿任何具体游戏、电影或艺术家的名称、角色、道具和场景。

### AI 绘图提示词模板

> 将中括号替换为具体内容；优先用中文生成，必要时在末尾补充英文材质和镜头关键词。

```text
蛋宝宝 IP 的温柔 CG 魔幻冒险场景：一只[角色：玉兔/锦鲤/其他蛋宝宝]，
拥有细密短绒的毛绒玩偶材质、圆润比例、简单可爱的表情，穿着/带着[1–3 个标志性配件]；
正在[一个明确动作]，位于[自然场景]。画面有[前景元素]、[远景地标]，
[时间]的自然侧逆光，柔和电影级体积光与空气透视，角色与[水/沙/草地/石头]产生真实接触，
可触摸的织物、橡胶、皮革和自然材质细节；广阔但安静、童话但不幼稚、轻度魔幻、温暖治愈。
构图为[横版 16:9 / 竖版 4:5]，主体置于[位置]并保留[位置]干净留白用于文案，
high-end stylized 3D CGI, tactile plush texture, cinematic natural lighting, soft depth of field.

避免：真实人类、塑料玩具、赛博霓虹、武器战斗、强烈魔法阵、满屏粒子、文字、水印、品牌 logo。
```

### 示例：官网首屏沙漠骑行

```text
蛋宝宝 IP 的温柔 CG 魔幻冒险场景：一只燕麦白短绒玉兔，戴红白复古头盔和护目镜，
头顶坐着一只小黄鸭，骑在一条同样是短绒质感、背着棕色皮革马鞍的大锦鲤背上，
穿过日落时的沙漠平原。锦鲤穿着明黄色雨靴奔跑，脚边扬起轻柔尘雾；
前景有低矮仙人掌，远方有暖红色岩柱和层叠沙丘。金色侧逆光，柔和长阴影，
广阔、安静、好奇、像一场刚刚开始的远行。横版 16:9，角色位于画面右侧，
左侧保留干净天空与远景用于标题。high-end stylized 3D CGI, tactile plush texture,
cinematic natural lighting, soft atmospheric perspective.

避免：文字、logo、真实人类、塑料质感、武器、战斗、霓虹、强烈粒子。
```

## 8. 上线前视觉自检清单

- [ ] 不看 Logo，是否仍能认出“蛋宝宝”的绒感角色与暖黄识别点？
- [ ] 角色是否在做一件具体的小事，而非只是在摆拍？
- [ ] 场景是否有远近层次、自然光向和一个值得探索的小细节？
- [ ] 角色是否真的接触环境，具有重量和物理反馈？
- [ ] 高饱和色、发光和动效是否只用于引导注意，而非填满画面？
- [ ] 将画面裁成横版/竖版后，表情、配件和文字安全区是否仍完整？
- [ ] 文案是否像一次温柔观察，而非任务、奖励或战斗号召？
- [ ] 小程序界面是否依旧让用户快速读懂状态和下一步操作？

## 9. 最终判断标准

一张合格的蛋宝宝视觉，不是“特效很多的 CG 图”，而是让人感觉：**这个毛绒小伙伴真的在一个辽阔又善意的世界里生活，而我随时可以轻轻走进去陪它一会儿。**
