# 长期收藏卡体系研究摘要

日期：2026-07-14

本研究只引用 Wizards of the Coast（Magic: The Gathering）、Topps、PSA 的第一方资料。观察到的行业机制与对 eggbabe 的建议分开记录；本体系不承诺任何未来价格或升值。

## Magic：套装位置与同卡异版是不同概念

- Wizards 说明，collector number 表示一张卡在某个套装中的位置，便于收藏者整理整套卡牌。[Anatomy of a Magic Card](https://magic.wizards.com/en/news/feature/anatomy-magic-card-2006-10-21)
- Magic 使用 set code、collector number 和 rarity 形成稳定的套装身份；同一基础卡还可以有不同边框、无边框、foil 等 treatment，而不是把每种视觉效果都混成新的基础身份。[MTG Product Guide](https://magic.wizards.com/en/product-guide)
- Magic 只有在真实限制总量时才使用 serialized treatment；例如官方会明确每种序列版的总量，而且序列版与普通版在功能上相同。[Collecting Ravnica Remastered](https://magic.wizards.com/en/news/feature/collecting-ravnica-remastered)

可迁移原则：基础卡身份、套装清单位置、视觉版本、实际副本序列号必须分开。

## Topps：Base Set 是骨架，Parallel 与 Insert 是后续层次

- Topps 将 Base Card 定义为一个产品的核心，卡号用于识别和完成整套收藏。[Topps Official Collecting Guide](https://www-next.topps.com/pages/start-collecting-topps)
- Parallel 保留基础卡身份，只改变颜色、纹理、图案或材料，并通常比基础版更少。[Topps Official Collecting Guide](https://www-next.topps.com/pages/start-collecting-topps)
- Topps 的编号平行版会直接公布总量；签名或 relic 的价值来自真实签署或真实物料来源，而不是装饰性文案。[Topps Inception MLS](https://www.topps.com/pages/topps-inception-mls)

可迁移原则：先建立可理解、可完成的基础套装；平行版和主题插入卡只能建立在稳定基础套之上。

## PSA：收藏信任来自认证、公开数量和清单完成度

- PSA 把真伪认证与实体品相评级分开；认证通过后才按 1–10 评价实体状态，并显示独立认证编号。[PSA Grading Standards](https://www.psacard.com/gradingstandards)
- PSA Population Report 提供具体物品在各等级下的数量，并持续更新。[PSA Population Report](https://www.psacard.com/Pop)
- PSA Set Registry 让收藏者按照 checklist 追踪整套完成度。[PSA Set Registry FAQ](https://www.psacard.com/psasetregistry/faq)

适用边界：数字卡没有边角磨损和表面划痕，不照搬 PSA 品相分。eggbabe 应借鉴的是唯一认证号、公开发行数量、不可变版本快照、清单与完成度。

## 对 eggbabe 的研究结论

1. 必须区分套装清单号、视觉版本、用户唯一副本号和真实限量序列号。
2. 第一季先冻结现有 10 张基础清单，只发布 `BASE`，不要在业务未验证前制造大量稀有度和平行版。
3. 只有后端能原子性停止超额发行，并公开发行上限时，才允许显示 `037/099` 一类限量序列号。
4. 数字收藏价值优先来自官方 checklist、单卡验证、发行数量、获得记录和版本快照，而不是复杂特效。
5. `1600×2000` 适合作为下一版 4:5 Hero 数字素材；未来实体卡需要独立印刷比例、出血、安全区和 300 DPI 规范。
