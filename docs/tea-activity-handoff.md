# 窗边茶会前端交付

2026-09-28。用户已确认选茶后需第二次确认、现有窗边图、退出保留进度、完成时结算，以及“清茶 / 花茶 → 回应 → 确认”简版。

## 当前已做

- 星星适配器提供活动开始、选茶、确认、收下四步合同，使用本次运行内状态；未接服务端。
- 选择仅进入待确认状态；没有选择不能完成；重复确认不重复扣星。
- 已开始的活动重进返回原进度，结果未收下前也不创建第二场。
- 首次活动免费，首次结果收下后后续茶会20星；余额不足不开始。
- 收下使用已有纪念册收录方法，宠物更换隔离活动状态。
- 照片必须显式传入，没有配置不开始。适配器固定使用已确认的完成时结算，不保留开始扣星策略。

## 用户入口与边界

- 房间右下百宝箱 → 纪念册 → 活动 → 窗边茶会 → 开始（首次免费）/继续 → 清茶或花茶 → 对应回应 → 确认 → 窗边照片 → 收下入册。
- 房间通过eventChannel传入当前宠物对应、当前时段的窗边照片，玉兔与锦鲤共用同一流程，不跨角色代用。
- 外出时不能开始居家茶会；已有进度与结果可恢复。关闭面板或退回房间不完成、不扣星，运行内保留；关闭小程序后的恢复不承诺。
- 照片预加载成功才允许确认；失败可重试，失败期间不扣星、不完成。重开结果后也须确认图片加载才可收下。
- 已通过茶会适配器与页面行为Node测试；原生模板和样式编译检查通过。手机视觉、点击手感与相册行为仍须人工验收。
- 首次免费资格只在本次运行内保存，真实持久化由CTO接入；已通过 PR #6 合入 main，未发布；手机视觉仍需人工验收。
- 测试中的虚拟照片仅用于Node行为测试，用户流程使用已有运行时素材。
