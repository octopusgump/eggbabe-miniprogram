## 一、这是什么

让用户与宠物完成一件小事，得到明确反馈，留下回忆，并期待下一次相处。

**核心闭环**：今日陪伴 → 获得星星 → 明日期待 → 纪念册 → 下一次共同活动。

体验保持简单：不做复杂养成面板、排名、人民币充值或星星抽奖。

| 概念 | 用户看到 | 含义 |
|---|---|---|
| 星星 | 可用余额 | 陪伴获得；可兑换指定纪念内容或参加活动；不涉及人民币 |
| 一起 X 天 | 累计有效陪伴日数 | 同一天最多 +1；间断不清零；消费星星不减少天数 |
| 回忆 | 照片、真实作品 | 已留下的共同经历 |
| 活动 | 可参与的小事 | 用户实际选择或创作，得到对应结果 |
| 明天呢？ | 下一次相处的线索 | 不是领奖励，也不是「进入聊天」文字按钮 |

**单个事件闭环**（COO 2026-10-04）：事情发生 → 用户参与 → 宠物回应 → 获得结果 → （可选）后续延续。

今日信件事件只分三类（互斥）：**日常陪伴、外出牵挂、特别奖励（reward）**。原「共同创作」「特别活动」并入 **特别奖励**（创作向：一起画；活动向：茶会等 B 类），不再单独占类。随机惊喜是事件内额外反馈，不与之并列。细则见主 PRD §3.0。

### 1.1 今日信件三类（摘要）

| 类 | 一句话 |
|---|---|
| 日常陪伴 | 在家，信内一次选择或短互动 |
| 外出牵挂 | 外出，信内纸条/牵挂 |
| 特别奖励 | 信内核心为一起画（创作向）或茶会等多步 B 类（活动向） |

判据顺序：外出 → 创作向 → 活动向 → 日常。废止「事件四类」。完整表见主 PRD §3.0。

## 二、生命周期与项目边界

### 2.1 只在破壳后生效（重要）

| 阶段 | IAA 星星 / 信件 / 纪念册 / 一起画 | 说明 |
|---|---|---|
| **破壳前**（孵化小房间） | **不参与** | 左上角不展示陪伴星星余额；「画画」仍是画蛋壳，不走信件发星闭环 |
| **破壳后**（生活空间） | **完整闭环** | 左上星星 + 一起 X 天；左下信件；百宝箱 → 纪念册；破壳后「一起画」 |

全产品里的 `companion_started_at` 用于**环境计算**（破壳前起算陪伴日季节等），**不等于**本文的「累计有效陪伴日数」（须完成当日核心陪伴动作才 +1）。

### 2.2 交付边界

**确认的产品目标 ≠ 已经交付的功能。**

| 范围 | 状态 | 说明 |
|---|---|---|
| 信件、明日角色、画画双份奖励、纪念册、窗边茶会 | 前端已合并 | 当前为本地模拟；按规则与验收清单核对 |
| 星星阶梯与有效陪伴日数 | 前端已合并 | 真实账户与服务端结算 → CTO，不阻断静态 UI |
| 兑换照片、随机惊喜、轻答题、旅行、带码分享 | 方向已确认 | 未完整交付；细则见决策清单，不得按未定义数值开发 |
| 共同经历 / 长期喜好 | 产品目标 | 模型与记忆 → CTO；当前不得冒充已接入 |
| 道具、更多活动 | 第二期 | 不在本轮 |

**本轮不做**：人民币充值、星星抽奖、排行榜、复杂成长面板、GIF 角色动画、「它记得的喜好」设置列表。

**保留**：完整聊天能力；**外出时不能聊天**（明日角色也不出现）。

**角色**：COO 体验/文案/前端；CTO 账户/语音/模型/记忆/服务端规则；CEO 知情或确认定位边界；法务确认上线合规。

## 三、主流程（破壳后生活空间）

1. 进入房间：左上 **星星余额 + 一起 X 天**；左下信件；当天首次进入有轻量到信提示（不自动弹信）。
2. 点击信封读信：了解今日小事；**无**自动展开弹窗。
3. 完成核心动作：普通日一次选择；外出日回应纸条；**特别奖励**日按对应流程（一起画 / 茶会等多步活动）。
4. 在对应结算点展示 **+X 星** 与宠物回应；同类每日额度不重复发放。
5. 用户主动点 **「明天呢？」**：看线索；在家时宠物探出，点角色进完整聊天。
6. 有照片或作品时点 **「收下」** 进纪念册；收下不决定是否已发星。
7. 百宝箱 → 纪念册 → **回忆 / 活动** 切换。

**内容扩充原则**（COO 2026-10-04）：以内容变化为主、逐步加玩法；选择至少改变当次回应；随机惊喜附着在已确认的基础结果之上。当前不授权远程模型、用户画像或真实记忆服务。

## 四、房间与信件

### 4.1 入口布局

- **左上**：星星余额、「一起 X 天」；保留时钟；破壳后房间不单独再挂一套「今日心情」入口（与全产品心情组件分工见 04 PRD）。
- **左下**：圆形信封；在家/外出同一入口；未读小红点，**打开信即消失**，不要求先完成活动。
- **右下**：设置（齿轮）；其上有 **百宝箱** → 小弹窗，首项 **纪念册**。
- 首次有可收藏回忆时，轻量引导打开百宝箱，不做多步强制教学。

### 4.2 到信提示

- 北京时间每天**首次**进房间：左下按钮内纸飞机 → 信封，约 **1 秒**；禁止横穿房间的大动画。
- 可选短音效 ~0.28s，遵循静音；当天重进不重复；播失败不阻塞读信。

### 4.3 信纸

- 居中浮层，可见房间背景；可点遮罩或关闭钮关闭。
- 展示：今日内容、核心动作、回应、「明天呢？」；心情可融入文案，不另加仪表。
- **废止**：「陪伴 / 聊天」分栏、「进入聊天」文字按钮；信件**不**写入完整聊天记录。

外出示例（模拟内容，非自动生成接入）：

> 房间里留着一张小纸条。  
> 「我去看看风把叶子吹到了哪里，晚一点回来。」  
> 操作：替它收好纸条。  
> 回应：你把纸条压在杯子旁边，等它回来。

### 4.4 明天呢？与聊天

| 情况 | 行为 |
|---|---|
| 点击「明天呢？」 | 不发星、不加陪伴日；完成活动后**不**自动展开 |
| 在家 | 展开明日线索；玉兔/锦鲤从信纸右下探出 ~1s（**静态图**，无 GIF）；点角色 → 聊天页 |
| 外出 | 只展示线索；**无**聊天角色；不能进聊天 |
| 在家但有聊天限制 | 角色仍可见；点击说明限制并保留信纸 |
| 当天重进 / 从聊天返回 | 保留展开状态；不重播入场；次日重置当日提示 |

明日内容优先：共同活动、用户明确兴趣与主动愿望；不默认把每次聊天变成次日提醒。

## 五、星星与有效陪伴日

### 5.1 基础阶梯（按累计有效陪伴日）

当天**首次结算**时冻结「当日基础星」，同日后续结算不再改基数。

| 累计有效陪伴日 | 当日基础星 |
|---:|---:|
| 1–2 | 10 |
| 3–6 | 11 |
| 7–13 | 12 |
| 14–20 | 13 |
| 21–29 | 14 |
| 30–44 | 15 |
| 45–59 | 16 |
| 60–89 | 17 |
| 90+ | 18 |

若今天尚未记有效陪伴，首次结算按 **「已有有效日 + 今天」** 算基数（例：已有 2 天，今天开画成功 → 开始奖 11 星；画好再 11 星）。**打开画板本身不加「一起 X 天」。**

不生息、不按余额计息、无多种倍率。

### 5.2 结算点（摘要）

| 动作 | 星星 | 有效陪伴日 |
|---|---|---|
| 读信、关信、点「明天呢？」 | 无 | 无 |
| 完成普通核心动作 | 基础奖 ×1（当日） | 当天首次有效 +1 |
| 「一起画」且画布就绪 | 基础奖 ×1（与普通**共用**一次基础额度） | 无 |
| 「画好了」且导出成功（有真实笔迹） | 额外奖 = 冻结基数（当日首次） | 当天首次有效 +1 |
| 重复进入/重复完成画画 | 不重复 | 不重复 |
| 收下作品 | 无 | 无 |
| 茶会确认完成并产生照片 | **无星、无普通基础奖** | 当天首次有效 +1（与普通/画画**共用**每日一次） |

- 常规一日最多 **两份基数**，封顶 **36 星**（随机额外奖另计，未定义部分不计入该封顶）。
- 先普通后画画：进画不再发第一份基础，画好仍可拿额外奖；**有效日全天仍最多 +1**。
- 日界：**Asia/Shanghai** 自然日；断开不清零、不补签；消费只减余额，不减累计日数或升档资格。

### 5.3 反馈

- 信纸上方：**真实 +X**、约 2s 大星挤压弹出；不新开奖励窗。
- 关信后：左上余额更新 + 轻量回应；**不重播**挤压/声/震。
- 信纸内装饰光点 **≠** 实际收入。
- 减弱动态效果：静态数值反馈；静音不影响结算。

## 六、一起画（破壳后）

破壳后新增；复用破壳前画板工具（画笔、橡皮、贴纸、撤销、清空）；完成钮 **「画好了」**。**不改变**破壳前蛋壳保存逻辑；陪伴作品**不**写入蛋壳。

**正常路径**：信邀 → 一起画 → 画布就绪（发未领的基础奖）→ 创作 → 画好了导出 → 额外奖 + 记有效日 → 信纸见作品与回应 → 可选收下。

**完成条件**：至少一笔真实非橡皮笔迹；空白/仅贴纸/仅擦除不算；不评分、不限时；文字语音解释可选，不因多说多发星；不假装看懂未解释的画面。

**边界（摘要）**：中途退出保留开始奖与运行内草稿，无完成奖；导出失败可重试；跨日恢复旧稿不自动发今日基础奖，今日完成仍按今日规则；重复提交不重复结算。

## 七、纪念册与活动

### 7.1 结构

- 顶栏两词：**回忆**｜**活动**。
- **回忆**：照片与用户真实作品；刚完成的结果可直接收下，不得再花星买一遍。
- **活动**：名称、说明、费用或首次免费、可续进度；文案形如「开始 · 需花费 X 星」。余额不足或拒绝邀请**不影响**普通陪伴。

### 7.2 星星两种用途

| 类型 | 说明 | 本轮 |
|---|---|---|
| A 兑换指定纪念内容 | 第一版仅 **照片** 一种 | **待实现**（规则已定，见下） |
| B 共同活动 | 须实际参与，保证基础结果 | **窗边茶会** 已交付前端 |

- 每个 **活动向** 特别奖励 SKU（如茶会）首次完整免费，后续花星；邀请在信件中低频出现，不自动弹消费窗。
- A 与 B 并存，无强制消费比例。

**兑换照片（待实现，产品已定）**

- 入口：百宝箱 → 纪念册 → 活动 → **兑换照片**。
- 主题首版：**宠物的窗边午后**（玉兔/锦鲤各一张新拍立得，不复用茶会图）；配文方向：「午后的光刚好，给你留一张我的照片。」
- 兑换前：只显示 **配文 + 10 星**，**不**展示完整图/缩略图/模糊预览。
- 用户确认后才揭晓并入纪念册；准备成功才扣星；失败不扣、可重试；已拥有显示「已拥有」可查看不重复扣；余额不足提示「星星还不够」，可返回。
- 与纸条惊喜照片、刚完成作品、已有陪伴照片**不是同一套内容**。

### 7.3 窗边茶会（已交付前端）

- 入口：百宝箱 → 纪念册 → 活动 → **窗边茶会**。
- 首次免费；选清茶/花茶有短回应，**选择不算完成**；须再点 **确认 · 免费** 或 **确认 · 需花费 20 星**；照片加载成功才结算。
- 完成才扣 20 星或消耗免费；开始/中途退出不扣。
- 展示宠物对应现有窗边图 +「一起在窗边喝了一杯茶。」→ 收下进回忆。
- 外出不能**新开始**茶会；已有进度/结果可继续。
- **计日**：确认完成产生照片 → 可记当天有效陪伴（不发星、不领普通基础）；与普通/画画**共用**每日一次有效日；仅进入/选茶/失败/收下不额外加日。

## 八、关系与输入（原则）

- 每次陪伴一个明确核心动作；文字/语音辅助理解意图，不要求每天说话。
- 「今天不想画」≠「不喜欢画」；长期喜好需用户明确表达才可进记忆目标；推测需轻确认；**无**喜好列表设置页。
- 关系深化：引用共同经历、贴合喜好、选择影响后续；第一期做可验收小链路。真实记忆与模型安全 → CTO。
