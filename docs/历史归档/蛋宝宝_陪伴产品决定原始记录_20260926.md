## 基础星星与陪伴日数（Q59，后续奖励时机已修订）

用户明确“同意，请执行”。本节覆盖所有早期每日 1 星、小数收益、按历史累计星星成长及一两年封顶的候选方案；下方编号记录保留讨论经过，不作为冲突规则执行。

| 累计有效陪伴日数（含当天） | 每日基础星星 |
| ---: | ---: |
| 1–2 | 10 |
| 3–6 | 11 |
| 7–13 | 12 |
| 14–20 | 13 |
| 21–29 | 14 |
| 30–44 | 15 |

| 60–89 | 17 |

- 上海自然日首次完成有效陪伴：累计陪伴日数增加 1，按增加后的日数结算基础星星；没有完成时不增加日数、不发基础奖励。
- 同日继续参与不重复发基础星星、不重复增加日数；其他事件的额外随机奖励按各自规则制定，不计入陪伴日数、不乘收益倍率。
- 缺席不清零；花星只扣余额，不减少“一起 X 天”与基础收益资格。
- 星星余额与本次奖励均显示整数，不再使用小数星星。用户界面仍称“一起 X 天”，不展示等级、经验条。
- 一次收取可用 3–5 颗装饰小星汇入余额，最后显示实际 `+10` 至 `+18`；装饰数量不代表真实奖励数量，不必生成与奖励数相同的动画星星。维持克制、减少动态效果时保留静态数值反馈。
- 兑换与活动价格必须按新面额制定，目前未定价。按需要多少有效陪伴日才能负担来检查价格，不自动乘用旧价格。
- 本节是已确认产品规则；当前真实仓库仍是旧 `+1` 静态演示，累计日数、阶梯结算及上述小星汇入效果尚未按新规则实现。

边界验收：第 1/2 日为 10，第 3/6 日为 11，第 7/13 日为 12，第 14/20 日为 13，第 21/29 日为 14，第 30/44 日为 15，第 45/59 日为 16，第 60/89 日为 17，第 90 日及之后为 18；重复完成、跨上海日界、缺席与消费分别验证。
