## 流程摘要

1. 入口：信件（免费）/ 活动页 / 桌面（花 **20** 🌟，与活动 list 一致）。
2. 首次教程（不消耗看一看次数）→ 自动看一看约 **5s**（**不计** 3 次额度）→ 作画。
3. 「再看一眼 · X/3 次」：手动再看，每次约 5s，共 3 次。
4. 「画好了」须满足 v2 三门（见下）→ 彩色道具展示 + **+10** 🌟（每次新 completionId；同日可无限次）。
5. 本阶段 **无** 收下 / 纪念册。

## 通过标准（v2 本地门槛）

- ≥5 笔真实画笔（touchstart→touchend 各 1；撤销不计；贴纸/纯橡皮不算）。
- 有效作画累计 ≥15s（idle >1.2s 不计）。
- 蛋形区域 10×10 格，画笔经过 ≥5 格（橡皮不扣格）。
