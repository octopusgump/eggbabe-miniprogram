# 听你说实施与验收（2026-10-19）

对应工单：[听你说 #36](https://github.com/octopusgump/eggbabe-miniprogram/issues/36)。本次不合并 main，由 COO 审查后决定。

依据：[在线《听你说 PRD》](https://chatgpt.com/space/page_ea411ab6eca0819189b8d22176396b79) 与 2026-10-19 导出的 schema 2.0.0 题库。分支 `feat/listen-answer-feedback-20261019`，基线 `origin/main` 的 `7ef8ee4`。本次是本机前端实现，不接模型、远程接口、数据库或跨设备同步。

## 已确认的行为

- 保留破壳前早教班；破壳后新增独立“听你说”。从房间现有信件进入，不新增房间按钮。
- 信件每天随机邀请一个可参与活动，同一天保持不变。活动配置可扩充小游戏；当前为听你说与一起画。外出纸条按原流程保留。
- 每组固定五题，单选，最后一项“都不是...”。选项下方可补充“写下你的想法...”，不必填写，也不加“我想自己说”标题。
- 跳过本次与中途退出均保留本机草稿，下次进入听你说时接着答。题组跨日完成按完成当天计算。
- 每天最多完成五个不同类别；首类随机，后续从剩余可用类别选择。每类按顺序推进；该类题组用尽后暂停，不循环。全部用尽时等待内容补充。
- 每组完成都显示一条预写反馈。三个条件反馈先核对全部要求与排除项；符合多条时选支持题数最多的一条，并列或均不符合时用本组保底。只使用选项，补充文字只保存；不拼接、不调用模型。
- 当天首次完成信件引导的有效活动领取一次基础星星并计入一个有效陪伴日。开信、进入画纸不领取也不计日。答题、一起画和纸条互动共用这一份基础奖励。
- 基数按上海自然日连续有效日计算，包含今天；中断后重新从第 1 天算。当天首次完成时冻结基数。题库进度不清零。
- 一起画的 +3 小回礼沿用既有规则，独立于基础星星；茶会原本不计日、不发基础星星的例外保留。
- 成功结算且本次确实新增基础星星时，答题反馈页播放现有约两秒的动画、音效与轻震，显示 +N。其余直接展示宠物反馈。重开、返回房间不重复领奖或重播。
- 本机状态按环境、当前用户与宠物隔离。组完成与奖励写入同一份记录，保存失败不推进题库、不发星，保留输入重试。

## 施工顺序

1. 导入原始题库，建立纯选项反馈匹配与题组进度规则；验证 26 组、130 题、650 选项、104 条反馈不变。
2. 建立本机记录与共享完成结算；迁移原画画开始奖励，保留 +3 小回礼。
3. 实现原生答题、反馈及继续选类别界面，沿用早教班字体声明和已确认反馈布局与现有宠物、星星素材。
4. 把信件按钮按活动类型分发，随机邀请稳定到当天。同步房间的对应活动完成状态，避免把领过星等同于所有活动完成。
5. 更新现行 IAA 主 PRD、术语及 CTO 接口交接；运行测试、项目检查和未参与实现者的代码审核。
6. 交 COO 在微信开发者工具中从真实房间入口验收。未经确认不合入 main、不上传小程序。

## 验证清单

- 匹配：单条、多条不同支持题数、最高并列、排除条件、五题都不是、仅改变补充文字；枚举所有组的选项组合。
- 答题：保存与恢复、快速连点、第五题重复提交、失败重试、跨午夜、每天排除已答类别、每类顺序、题库用尽。
- 星星：听你说先完成／一起画先完成均只发一次基础；+3 仍独立；开信与画纸准备不计日；断日重算、全部阶梯边界、旧结果次日重开不补领。
- 隔离：关闭重开、切换用户/宠物/环境、退出后清理按现有约定、本机写入失败。
- 页面：所有注册文件与素材可解析，早教班不变，develop/trial/release 用户功能一致；退出/后台取消音效与震动。

## 交接限制

自动测试不代表视觉通过。当前数据只有本机副本；正式接入后由 CTO 提供可信日期、持久化、幂等及奖励结算，页面通过 adapter 替换。画画草稿和茶会的既有范围不扩大。

## CTO 适配边界

- 内容源 `fixtures/listen-bank.json` 保留原编号与文字。微信运行载入同内容的 `listen-bank.js`，用 `node scripts/generate-listen-bank.js --check` 验证，更新题库时生成一次即可。
- `listen-adapter` 提供读取当前状态、开始题组、保存草稿、完成题组、读取结果及确认已看反馈；返回沿用 `{ok,data}`／`{ok:false,error}`。页面不直接调用网络。
- 草稿包含 groupId、categoryId、questionIndex、逐题 optionId 和 text、contentVersion。完成记录保留整组答案、反馈 ID／整条文案、完成日期和实际奖励结果；不会把文字转成用户画像。
- 共享结算返回 `baseAwardedStars`、`giftStars`、`effectiveAdded`、`duplicate`；0 星不等于重复提交。重复结果会返回原反馈，本次新增星星为 0。
- 本机一次写入保存完成记录、类别进度、每日类别与基础奖励；失败回滚全部状态。题组完成日期与奖励日期在同一个结算时刻确定。
- 记账连同已有照片权益、茶会扣星状态保存，避免重开后重复扣星。画画编辑草稿仍沿用运行内保存，不承诺关闭小程序后恢复画布。临时作品图片也不等于永久文件托管。
- 本次不更新在线 Page、飞书文档和 HTML 草图；它们是已确认内容／设计参考。分支里的 IAA 主 PRD 同步本轮共享奖励规则，作为 CTO 对接差异说明。
