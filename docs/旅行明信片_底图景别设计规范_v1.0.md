# 旅行明信片底图景别设计规范 v1.0

> 文档状态：可复用美术生产规范
> 更新日期：2026-08-08
> 适用范围：蛋宝宝旅行明信片的**无角色环境底图**及基于其生成的单角色动作图。
> 上位文档：[蛋宝宝旅行明信片内容与美术规格 v1.0](蛋宝宝旅行明信片内容与美术规格_v1.0.md)。本文只定义镜头、景别、空间与生成锁定条件；产品送达、正式目录、内容与数据规则以该上位文档为准。

## 1. 目标

每个旅行目的地都应像破壳后小房间一样，是一个可进入、可停留、可反复发生小动作的空间，而不是旅游海报或城市照片。

底图的职责是同时完成四件事：

1. 让用户一眼知道地点与氛围；
2. 让玉兔有一个明确、可信的站立或坐下位置；
3. 让小动作能在同一场景中连续发生；
4. 让每张动作图保持同一镜头、地面与尺度，便于在明信片回放中连续浏览。

## 2. 核心原则

### 2.0 底图画面规则（生成前必核对）

每张底图必须同时满足以下四项，缺少任一项都不进入动作图生成：

1. **近景、中景、远景齐全**：近景提供可触摸材质和局部遮挡；中景承载日常故事与角色互动；远景提供地点识别与空间纵深。三层不能压成一堵平面背景。
2. **有贴近日常的生活细节**：例如自动贩卖机的饮料陈列与饮料罐出口、木长凳、小盆栽、咖啡杯、纸袋、落叶，以及雨后地面的柔和反光或晨光投影。这些细节应让用户感到“这里真的有人生活”，同时为小动作提供可互动的对象。贩卖机可以有真实商品分格、按钮和出口，但不得出现可识别的品牌、包装文字或 Logo。
3. **45° 左右半俯视与 2.5D 景深**：镜头应能同时看到地面、桌面／台面、立面和远处环境；通过前景遮挡、中景活动区与远景地标形成可进入的空间。不得退化为平视街拍、正俯视地图或单纯城市全景。
4. **预留角色互动留白**：中下部必须保留连续、清楚、可承重的动作区；留白不是空洞，而是让玉兔能够站、坐、跳、抱物或与道具互动的空间。动作区不得被大型家具、文字、强反光或复杂植物边缘占满。

### 2.1 先锁景别，再换动作

一个 `scene_id` 只对应一个确认的无角色底图。后续所有动作图必须以该底图为环境参考，**只增加一只玉兔与该张必要的动作道具**。

不得随动作改变：

- 镜头高度、俯仰角、裁切、地平线、消失点；
- 地面平面、台阶、桌椅、门窗、建筑、植物和远景地标；
- 主光方向、时间段、阴影方向与整体色温；
- 角色活动区的位置与可用面积。

禁止把上一张“带角色动作图”作为下一张的环境参考。它会把动作造成的透视误差逐张累积，最终形成底图漂移。

### 2.2 旅行底图应是“室外的小房间”

推荐使用从左前方或前方上方观看的半俯视三分之四镜头。空间必须有明确的近、中、远景与可触摸的边界，而不是平视街拍、鸟瞰地图或城市全景摄影。

破壳后小房间所提供的关键感受是：暖木、织物、陶器、植物、可见的地面平面、柔和晨光和有呼吸感的景深。旅行底图应转译这些特征，而不是复制室内家具。

### 2.3 环境先于角色

角色是场景中的生活痕迹，不是巨型主视觉。底图要在不出现玉兔时仍然成立；加入玉兔后，用户才发现“ta 正在这里做一件小事”。

## 3. 标准景别模型

### 3.1 横版画面分区

画布固定为 1600 × 900，横版 16:9。建议按下图规划，而非机械平均切分。

```text
┌──────────────────────────────────────────────────────────┐
│  远景：目的地识别、天空、城市、山、塔或水面（约 20%–35%） │
│  中景：场景叙事与主要纵深，例如巷道、露台、工坊（约 35%） │
│  前景：可触摸材质与局部遮挡，例如木边、植物、桌角（约 15%）│
│  动作区：连续、平整、未被杂物占满的承重平面（约 20%–30%） │
└──────────────────────────────────────────────────────────┘
```

- **远景**：负责目的地识别，不做海报式地标特写。
- **中景**：负责叙事关系，如咖啡角、露台边缘、织机或沙滩。
- **前景**：提供材质、遮挡和进入感；不能遮住主动作区。
- **动作区**：是生成玉兔的唯一优先锚点，必须在底图阶段预留。

### 3.2 推荐镜头参数

| 项目 | 推荐值 | 目的 |
|---|---:|---|
| 俯视角 | 约 35°–55° | 既读出地面与道具关系，又保留立体远景。 |
| 机位 | 左前或前方三分之四 | 形成类似小房间的 2.5D 纵深。 |
| 动作区高度 | 画面下半部至中下部 | 让接地阴影可见，不压住地标。 |
| 地标占比 | 单个远景地标不宜超过画高 30% | 识别地点，但不夺走角色与动作。 |
| 景深 | 柔和、可辨识 | 背景可软化，木纹、角色、道具与接触面必须清楚。 |

不推荐：平视街拍、镜头过低仰拍、90°俯拍、建筑透视过强、远景只剩模糊色块，或角色不得不贴在空中。

## 4. 动作区与角色尺度

### 4.1 动作区的设计条件

底图必须预先提供一块连续的承重表面，例如：干燥石板路、木露台、草编垫、沙地或浅水边平坦沙滩。

动作区必须满足：

- 可读出表面材质与透视方向；
- 与桌、椅、贩卖机、栏杆等互动点距离可信；
- 没有大面积杂物、文字、强烈反光或复杂纹样干扰角色边缘；
- 允许短而紧的接触阴影落在角色脚下；
- 即使角色坐下、抱物、伸懒腰或轻跳，仍不需要改变底图构图。

### 4.2 玉兔比例锚点

| 项目 | 规则 |
|---|---|
| 完整身高 | 耳尖至脚底约占画高 32%–36%。低于 30% 或高于 38% 直接淘汰。 |
| 位置 | 默认位于中下部动作区；不顶住画面下缘，也不遮挡主地标。 |
| 接地 | 双脚、坐姿臀部或支撑双爪必须压在可见表面上。 |
| 阴影 | 接触阴影短、紧，方向与底图主光一致；不能是独立棚拍阴影。 |
| 角色身份 | 使用玉兔四视图；不得拉长、压扁、瘦身、长腿化或改五官。 |

### 4.3 动作空间校验

生成前必须回答以下问题：

1. 玉兔站、坐或支撑在哪个具体表面？
2. 身体朝向哪个操作面？
3. 双脚、臀部或双爪如何承重？
4. 道具是否处于两只短爪可及范围？
5. 阴影落向哪里？是否与台阶、桌腿、盆栽的阴影一致？

若无法回答，说明底图不适合该动作，应换动作或重做无角色底图，而不是硬改角色姿势。

## 5. 光线、材质与清晰度

### 5.1 破壳后小房间的视觉基准

参考：

`miniprogram/assets/scenes/lifecycle/post-hatch/10-background/panorama-three-screen/post_hatch_left_living_with_jade_rabbit_reference.webp`

必须转译的特征：

- 温暖、干净的自然侧光；
- 浅木材、织物、陶器、玻璃、植物与地面都有可触摸细节；
- 亮部柔和，不漂白；阴影温暖且有层次；
- 景深自然，远景柔化但不糊成色块；
- 角色边缘、bouclé 绒线、木纹、叶片、桌椅边缘与接触阴影清楚。

### 5.2 清晰度门槛

成图在 1600 × 900 下必须满足：

- 玉兔的眼睛、蓝鼻、腮边刺绣和绒线方向可辨；
- 动作道具边缘完整，不融入手掌或背景；
- 地面纹理和角色脚下阴影可辨；
- 近中景道具清楚，远景地标仍可识别；
- 不能用过强景深、雾、颗粒或锐化掩盖生成瑕疵。

## 6. 东京场景族锁定示例

### 6.1 咖啡巷 `alley`

锁定底图：

`scene_base_travel_tokyo_detailed_cafe_alley_45deg_v12.webp`

空间锚点：

- 左侧：暖木咖啡角、无品牌白色贩卖机、长凳、小桌、藤蔓与盆栽；
- 中央：干燥石板路，作为唯一主要动作区；
- 右侧：管线、设备、无字青／粉氛围光与少量植物；
- 远处：东京塔提供地点识别。

适合：踮脚选饮料、抱饮料、自拍、看相机回放、落叶小跳、热饮、许愿、晨间伸展、背对东京塔。

不适合：需要大幅奔跑、长距离跳跃、多人互动、大型载具或会遮住巷道的巨型动作。

### 6.2 暮色露台 `night_terrace`

锁定底图：

`scene_base_travel_tokyo_tower_fuji_compact_terrace_v10.webp`

空间锚点：下方小露台为动作区，东京塔、城市灯光与富士山是主要远景；不得扩大露台、移动塔或改天际线比例。

### 6.3 清晨露台 `morning_terrace`

锁定底图：

`scene_base_travel_tokyo_tower_fuji_morning_compact_terrace_v11.webp`

空间锚点：下方约 25%–30% 的木露台用于角色；淡蓝天空、杏金晨光、轻雾城市、东京塔和富士山是固定氛围。适合热饮看景、许愿、自拍、轻伸展等安静动作。

## 8. 验收清单

### 8.1 底图验收

- [ ] 16:9 横版，清楚的近、中、远景与可见地面；
- [ ] 已指定唯一动作区与互动点；
- [ ] 地标可识别但不海报化；
- [ ] 无角色、文字、品牌、Logo、二维码、UI；
- [ ] 符合破壳后小房间的光线、材质与清晰度；
- [ ] 已写入候选 manifest，未接入运行时。

### 8.2 动作图验收

- [ ] 使用“玉兔四视图＋锁定底图”两张参考输入；
- [ ] 玉兔完整身高 32%–36% 画高；
- [ ] 镜头、远景、地面、建筑与底图逐项一致；
- [ ] 动作、道具、承重和遮挡关系可信；
- [ ] 角色清楚接地，阴影方向正确；
- [ ] 玉兔身份未漂移：材质、耳朵、眼睛、蓝鼻、腮边刺绣、尾巴均正确；
- [ ] 无文字、品牌、第二角色、白边、贴纸感或透明后贴；
- [ ] 1600 × 900、不透明 WebP、约 q82；
- [ ] 仅通过人工终审的图可从候选目录升级为正式资产。

## 9. 失败处理

| 问题 | 正确处理 |
|---|---|
| 玉兔太小或太大 | 从锁定底图重生，只调整角色完整身高到 32%–36%。 |
| 镜头、巷子或露台漂移 | 丢弃该版本；不可拿动作图继续修环境。 |
| 动作不可信 | 保留底图，换一个能在动作区内承重的动作。 |
| 角色像贴纸或漂浮 | 从锁定底图重生，明确支撑面、接触阴影与遮挡。 |
| 材质或画面偏糊 | 用破壳后小房间作为清晰度／材质参考，重生而非过度锐化。 |
| 不合格底图 | 留在 `_candidates` 作为排除参考，不覆盖、不接入、不升级。 |
