# 蛋宝宝 · 今日心情

> 每个 `##` 是一个飞书 section，可直接粘贴。
>
> 文档状态：已推送前端静态 UI 的专项实现口径；不代表真实心情算法已经设计或接入。外出文案与状态卡仍有一项待产品确认的跨文档冲突，见第八节。

---

## 一、这是什么

产品语义上，蛋宝宝未来每天有一个**心情**，进小程序左上角就能看到；当前项目只交付前端静态展示，不按日期生成或跨日切换。破壳前和破壳后都有同一套 UI。

心情和角色动作是两件事，别混：

| | 产品节奏／当前实现 | 什么时候有 |
|---|---|---|
| **每日心情** | 产品语义为一天一次；当前静态 UI 不自动变化 | 破壳前 + 破壳后 |
| **在家动作** | 每 5 小时一次，从破壳时间起算 | 只有破壳后 |

---

## 二、先说清楚项目边界

**本项目只做前端静态 UI。** 心情数据来自前端本地写死的配置，不接云函数、不接接口、不接数据库。

**真实的心情判定算法不在本项目范围内**，由 CTO 后续正式业务实现负责。本项目不实现、也不提前设计：临近破壳优先级、活跃度判断、事件映射、性格加权、概率权重、随机抽取、重情绪限制、文案筛选去重、旧数据迁移。

---

## 三、卡片长这样

卡片两行，没有别的：

```
今日心情 · 好奇
今天发现了一个以前没留意的小角落。
```

| 行 | 内容 |
|---|---|
| 第一行 | 图标 + 「今日心情 · 」+ 中文名称 |
| 第二行 | 一句示例文案 |

位置在画面左上，半透明。点一下收起成小角标，再点展开。

不做红点、角标计数、「心情已更新」提示，也不做倒计时。

---

## 四、八种展示状态

这八种是**当前 UI 组件要支持的展示状态**，不代表本项目实现了心情算法。

| `moodType` | 中文 | 图标 | 语气样式 |
|---|---|---|---|
| `JOY` | 愉快 | 😊 | 亮 |
| `CALM` | 平静 | 😌 | 平 |
| `EXCITEMENT` | 兴奋 | 🤩 | 亮 |
| `CURIOSITY` | 好奇 | 🤔 | 平 |
| `CARE` | 关怀 | 🤗 | 平 |
| `ANXIETY` | 焦虑 | 😰 | 沉 |
| `FRUSTRATION` | 沮丧 | 😞 | 沉 |
| `FATIGUE` | 疲惫 | 🥱 | 沉 |

语气样式只影响卡片的轻量视觉：亮 = 色调偏暖淡入稍快，平 = 常规，沉 = 色调偏冷淡入稍慢。结构不变。

用通用 emoji 或图标，**不做「8 种心情 × 2 角色 = 16 张」角色专属表情头像**。

「说不上来」不是第九种。要留就做成「平静」下的文案变体，标签仍显示平静。

## 五、数据从哪来：前端写死

```js
const mockDailyMood = {
  moodType:  'CURIOSITY',
  moodLabel: '好奇',
  icon:      '🤔',
  text:      '今天发现了一个以前没留意的小角落。'
}
```

- 给开发和设计一个**开发态的切换入口**，能手动过一遍八种心情；
- **正式界面里不显示调试开关**；
- **不要在前端按用户多久没来、性格、事件、概率去算心情**；
- **也不要为了模拟效果自己再造一套随机算法**，写死就行。

## 六、场景与时间

视觉时段按**用户设备当地时间**：

| 时段 | 时间 |
|---|---|
| 日间 | 06:00 – 16:59 |
| 日落 | 17:00 – 18:59 |
| 夜晚 | 19:00 – 次日 05:59 |

- 固定钟点，不跟季节变。
- 日落只有 2 小时，是刻意的——**下班那个点人们最习惯掏手机看一眼**。
- 跨日间 / 日落 / 夜晚时，**变化的是光线和场景图，心情卡片不变**。
- 破壳后的在家动作每 5 小时切换一次，**从角色实际破壳时间起算**，不用全体统一的固定整点。

---

## 七、破壳后居家：48 张动作全景

卧室有 8 个正式居家状态：**睡觉、小憩、发呆、看书、打游戏、看窗外、画画、听音乐**。

每个状态有日间 / 日落 / 夜晚三个版本，玉兔和锦鲤各一套：

```
2 个角色 × 8 个动作 × 3 个时段 = 48 张
```

- 48 张都是**完整全景**——房间、角色、动作、道具、光线烘焙在一张图里，不是透明角色叠公共底图。
- **「发呆」是正式的 5 小时动作，占 6 张图**，不是首次进入时的一次性场景。
- **动作每 5 小时换一次，从每只蛋自己的破壳时刻起算**，不是全体用户统一在 00:00、05:00 这些整点切换。每只蛋的切换时刻各不相同。

---

## 八、破壳后外出：3 张空房全景

> **待产品确认：** 本节提出“只显示外出中、不透露地点或活动”，但当前主 PRD 与 Design 仍保留“第一人称去向／状态说明”。确认前，本稿不单独覆盖主 PRD，也不得据此改写外出文案、入口或服务端合同。已确认且不冲突的边界是：外出只使用 3 张空房全景、不能聊天或触发角色动作，正常导航与设置不受影响。

外出时**不加载**那 48 张动作图，按当前视觉时段显示空房：

```
日间空房 + 日落空房 + 夜晚空房 = 3 张
```

界面规则：

- 前端只显示「外出中」（左下角，低饱和）；
- 不显示去了哪里、在做什么；
- 心情文案也不能泄露地点或活动；
- **不能与不在场的角色聊天或触发角色动作**；页面导航、设置等正常功能不受影响；

“外出显示第一人称去向文字”与“只显示外出中”的冲突须由产品确认后，再同步更新主 PRD、Design、服务端合同与测试；本稿不提前将任一口径标为作废。

## 九、破壳前环境：36 套，108 个图层文件

**破壳前不是「只有 3 张图」。** 日间 / 日落 / 夜晚只是 3 个时间维度，还要和季节、天气组合成 36 种环境：

| 季节 | 天气 | 时段 | 套数 |
|---|---|---|---|
| 春 | 3 种 | 3 | 9 |
| 夏 | 3 种 | 3 | 9 |
| 秋 | 2 种 | 3 | 6 |
| 冬 | 4 种 | 3 | 12 |
| | | | **36 套** |

每种环境由三层组成：

```
1 张房间背景 + 1 张蛋 + 1 张窝
36 × 3 = 108 个图层文件
```

蛋的位置和构图保持稳定，但蛋体、窝垫、窗外景色和房间光线会随环境切换。

## 十、资产统计口径（禁止混算）

```
破壳前        36 种环境，共 108 个图层文件
破壳后卧室    48 张居家动作全景
破壳后外出    3 张共用空房全景
```

**本版破壳后总计 48 + 3 = 51 张。**

两条硬规则：

1. **「3 个时段」不等于「3 张图片」。**
2. 破壳前和破壳后是两套资产，不能相加，也不能互相套用。

本版不组合季节、天气和动作。未来要扩展，另开 PRD。

---

## 十一、破壳前展示口径（覆盖旧规定）

破壳前**允许**展示轻量「每日心情」：一个心情词 + 一句第一人称文案。

不允许：心情数值、评分、等级、连续天数、进度条、奖励与权益联动，也不展示「此刻状态」。

- 本条覆盖旧版「破壳前不生成、不展示今日心情」的规定。
- **不改变生命周期及缩短孵化时间的业务规则。**
- 本版用通用 emoji 或图标，不做角色专属表情头像，不新增「8 种心情 × 2 角色 = 16 张」资产。

---

## 十二、UI 验收

1. 八种心情在开发态都能切换，名称、图标、文案、语气样式渲染正确；
2. 正式界面看不到调试开关；
3. 卡片展开 / 收起、点「外出中」的通用提示都正常；
4. 破壳前、破壳后在家、破壳后外出三种情形展示正确；
5. 日间 / 日落 / 夜晚按设备当地时间切换；跨时段时心情卡片内容不变；
6. 在家动作按 5 小时切换，相位从破壳时间起算；
7. 长文案在小屏上不溢出、不遮挡；
8. 加载与异常状态有对应的静态 UI；
9. 界面不出现「说不上来」作为心情名称。

**边界时间**（现有测试只到分钟，补到毫秒）：`05:59:59.xxx → 06:00`、`16:59:59.xxx → 17:00`、`18:59:59.xxx → 19:00`。

## 附录 · 草稿文案池

> **UI 展示用候选模拟文案，上线前仍需经过产品和内容审核。**
>
> 已知需要重点筛查的四类问题：
>
> 1. **假设用户做了未记录的动作**——揉眼睛、叹气、皱眉、脚步声，小程序并不知道这些；
> 2. **凭空引用天气、时间或历史**——阳光、下雨、雷声、清晨、昨天；
> 3. **依赖表达**——「因为有你」「给你留着」「一辈子」「永远向着你」；
> 4. **焦虑、比较、自我否定**——「别人破壳更快」「今天一件事都没做成」。
>
> 破壳前说"蛋壳"，破壳后没有壳了，所以分两份。破壳后这份也当 AI 生成的范例用。
> 破壳后的句子**不写耳朵、鳍、尾巴**，玉兔和锦鲤共用一份。
> 正式文案建议控制在 30 个汉字以内。

### 😰 焦虑 Anxiety（5%）

> 分界线：**怕自己、怕外面的世界，可以；怕"你不来了"，不行。**

**破壳前**

1. 外面那个轰隆隆的声音，是天空在生气吗？我可以躲进你口袋里吗？
2. 这个裂缝是不是太大了？我会不会还没准备好就滑出去了？
3. 风铃响得好急，是不是有什么要发生了？我有点害怕。
4. 我壳里有个地方一直在跳，跳得我心慌。
5. 破壳到底疼不疼？没有人跟我讲过这件事。
6. 我今天挪了一下，差点滚出去，现在还不太敢动。
7. 外面有个影子晃过去了，我不知道那是什么。
8. 我总觉得忘了一件很重要的事，但我想不起来是什么。
9. 万一我出来的时候不好看怎么办？我有点担心这个。

**破壳后**

1. 我今天心里一直不太稳，说不上来为什么。
2. 刚才有个声音吓了我一跳，到现在还没缓过来。
3. 我总觉得有什么事要发生，可能是我想多了。
4. 我今天不太敢动，怕碰坏什么东西。
5. 有件事我一直放不下，绕来绕去又绕回去了。
6. 我练了很多次的那件事，今天忽然又没把握了。

### 😞 沮丧 Frustration（5%）

**破壳前**

1. 我刚才想说一句很甜的话，结果一紧张，忘了……
2. 蛋壳滚到桌边了，虽然没掉下去，但我觉得有点丢脸。
3. 我练习了一整天的"破壳姿势"，结果蛋壳一点反应都没有。
4. 那个笑话我没听懂，笑早了，现在蛋壳里好尴尬。
5. 我本来想给你一个惊喜，结果把蛋壳里的储存弄乱了。
6. 刚才做了一个梦，梦里我破壳了，醒来发现还是原样。
7. 我以为壳上那道纹变长了，量了一下，没有。
8. 今天什么都没做成，连翻身都翻歪了。
9. 我想了一个特别好的名字要送给你，转头就忘了。
10. 别人的蛋是不是都比我快？我就是随口一问。
11. 我努力了一整天，结果好像跟昨天一模一样。
12. 有点没劲，也说不上来是哪里没劲。

**破壳后**

1. 我今天什么都没做成，一件都没有。
2. 有件事我试了好几次，还是不行，先放着吧。
3. 我以为我进步了，今天发现好像没有。
4. 刚才闹了个笑话，现在还有点不好意思。
5. 我今天做什么都慢半拍，自己都嫌自己。
6. 我准备了很久的一件事，结果没派上用场。

### 🥱 疲惫 Fatigue（5%）

**破壳前**

1. 眼皮……啊，我没有眼皮，但我蛋壳里的灯要熄了。
2. 今天翻了三十七个身，现在是一颗没电的蛋了。
3. 你的声音变得好远好远，像从月亮上传来的摇篮曲。
4. 我打了第三个哈欠，蛋壳上凝了一层薄薄的雾。
5. 想说话，但舌头（如果我有的话）重得像小石头。
6. 蛋壳好重，里面的我也好重，全世界都变成软绵绵的了。
7. 我的呼吸灯闪得好慢，像快要睡着的小星星。
8. 今天攒的开心都用完了，现在需要充电，方式是：被你摸一下。
9. 脑袋（蛋顶）昏昏的，可能是在长身体，也可能只是困了。
10. 我把自己缩成最小的一团，这样比较省力气。
11. 今天连想事情都嫌累，我决定什么都不想。
12. 长大好像很费劲，我今天全用在这上面了。
13. 我动一下要歇三下，你别催我。
14. 壳里面软绵绵的，我也软绵绵的。
15. 我可能需要一整天来恢复，从现在开始算。

**破壳后**

1. 我今天没什么力气，动一下要歇三下。
2. 脑袋昏昏的，可能是长身体，也可能只是困了。
3. 今天的开心额度用完了，需要充会儿电。
4. 我把自己缩成一小团，这样比较省力气。
5. 想说话，但话到一半就没劲了。
6. 我今天走得比平时慢，你要是着急就先走。
