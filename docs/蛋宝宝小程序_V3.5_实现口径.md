# 蛋宝宝小程序 V3.5 实现口径

## 基线

唯一产品基线为 `PRD归档/蛋宝宝小程序_V3.5_PRD.md`。旧版 v2.29 与《孵化修炼手册 v1.3》只作为历史资料，不再用于决定当前行为。

## 已落地

- 孵化模型改为服务端权威的百分比修炼值：每满 24 小时被动增加 10 点，主动模块按 V3.5 固定表增加，总值封顶 100。
- 每日模块与一次性模块分别幂等；连续登录压缩只存在于服务端状态口径，界面不提示。
- 首页改为全屏场景，显性功能卡只保留“许愿池”和“修炼课堂”；轻触、长按心跳、涂鸦等动作由场景承接。
- 许愿池答案不再映射用户画像或蛋宝宝人格，删除画像用途二次同意及设置入口。
- 涂鸦使用唯一固定画笔，不提供笔刷档位或画布缩放。
- 修炼值达到 100 后仍必须完成昵称、出生礼物与孵化回顾，破壳页会逐项校验。
- 自定义底部导航和安全区适配已接入；生产首页不暴露演示工具栏。

## 冲突裁决

- PRD §6.3 将涂鸦描述为一次性，§7.2 明确写为每日 `+2`。采用更具体的 §7.2：涂鸦按日幂等。
- PRD §7.8 的示例仍出现 `time_reduced_minutes`，但 §7.3 已声明旧减时模型完全废弃。实现统一使用 `incubation_points`。
- PRD §0.1 出现 “v2.28” 字样，文档标题、版本表与需求上下文均指向 V3.5，因此按 V3.5 执行。

## 需要产品素材或法务结论后继续

- 出生礼物的可选内容、资源 ID 与视觉素材尚未提供；当前只实现服务端记录接口和强制破壳门槛，不虚构礼物选项。
- 性格小测试的题目、答案、结果模型与视觉素材尚未提供；当前只保留 `personality_test` 模块及 `+3` 契约。
- 各 IP 对许愿池、修炼课堂和破壳前说话的完整固定回复映射尚未提供；客户端优先展示服务端 `response_line`，缺失时仅使用中性兜底。
- “连续登录压缩且完全不提示”的合规风险在 PRD 中仍为待确认项；上线前必须取得书面法务结论。
