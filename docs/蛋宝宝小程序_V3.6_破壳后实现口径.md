- `PRD归档/蛋宝宝_日常陪伴系统_结构说明_v0.3.md` 补充空间和素材结构；两份文档冲突时以主 PRD 为准。
- 孵化前首页、一级入口、设备时钟、蛋壳绘图、许愿池和早教班继续沿用已确认实现，本轮不改变其布局与业务规则。

## V3.6 破壳后落地

| 项目 | 当前口径 |
| --- | --- |
| 生活空间 | 固定左侧起居区、中间桌面、右侧布置区三屏连续空间；进入时定位到 ta 所在屏，用户可左右滑动查看空着的其他空间 |
| 此刻状态 | 以每只蛋的破壳时刻为起点，每 5 小时一个时段；同一时段刷新不改变 |
| 大场景 | 只使用家、旅行、打工、上学；用户不能手动选择 |
| 外出 | 三屏都显示空着的家，以第一人称文字说明去向，只提供写信；不显示旅行景区图 |
| 对话 | 只在固定允许说话的居家小场景中原地出现输入；不注册独立聊天页 |
| 右下角操作 | 居家且允许说话时显示嘴巴对话按钮，外出时显示信件按钮；百宝箱收纳我的 / 设置、收藏卡、明信片和 ta 带回来的东西 |
| 对应动作 | 每个小场景只有一个审核过的固定动作；能否说话同样由固定映射决定 |
| 回忆 | 完成对应动作后才留下该时段的纪念物；外出写信后待 ta 回家再出现对应物；未访问或未行动的时段不补发 |
| 日常窗外 | 复用当前上海天气、时段动效与第一人称陪伴文案 |
| 魔法窗外 | 只允许大理、北京、西双版纳正式景区素材；三张正式素材未齐前关闭入口 |
| 右侧布置区 | 本轮只保留空间边界。主 PRD 未放行 AI 生成额度、装饰列表与拖放存储，因此不注册相关页面和接口 |

## 状态与数据边界

- demo 数据存放在账号隔离的 `eggbabe_post_hatch_v36` 命名空间，用于状态、动作、寄信、回信与纪念物幂等回归。
- live 不由前端生成正式业务结果。服务端时间不可用、接口未接入或响应不完整时展示失败与重试。
- live 端点为 `getPostHatchHome`、`performPostHatchAction`、`sendPostHatchLetter`、`getPostHatchMemories`。
- 服务端返回的小场景 ID 必须存在于固定场景表；前端以固定表覆盖动作、所在屏和说话权限，防止随机映射。
- `slot_end` 只用于到点重新请求，不展示倒计时或预告。

## 素材状态

所有运行时路径集中在 `miniprogram/config/post-hatch-assets.js`。三屏采用“同一母版制作、三屏独立运行”：中屏直接复用破壳前 20 个正式状态背景，左屏和右屏各新增 20 张同 key 扩展图。每个状态必须左右两张一起通过验收后，才加入 `READY_PANEL_SCENE_KEYS` 原子启用；半套素材继续使用全景兜底。完整规范及 40 张新增素材清单见 `miniprogram/assets/scenes/lifecycle/post-hatch/10-background/THREE_PANEL_SCENE_SET_SPEC.md`。

当前左右屏正式状态素材、完整角色姿态、明信片、心情头像以及三张正式魔法窗景区图仍未齐；页面保留清晰配置边界，不把参考合成图、草稿或第三方图片接入正式配置。已有透明单件纪念物会按明确 ID 复用。
