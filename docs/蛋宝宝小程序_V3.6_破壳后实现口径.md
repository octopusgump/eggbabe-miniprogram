# 蛋宝宝小程序 V3.6 破壳后实现口径

## 文档优先级与范围

- 破壳过程及破壳后：以 `PRD归档/蛋宝宝_日常陪伴系统_结构说明_v0.3.md` 为最高优先级，`PRD归档/蛋宝宝小程序_V3_6_PRD.md` 为辅助。
- 孵化前首页、底部 Tab、设备时钟、蛋壳绘图、许愿池、早教班：继续沿用已确认的 V3.5，不由本次破壳后文档反向覆盖。
- 本次没有恢复系统左右滑动转场，首页场景仍以渐进放大进入、缩回退出。

## PRD 与 V3.5 实现差异

| 项目 | V3.5 现状 | V3.6 落地 |
| --- | --- | --- |
| 生活空间 | 六张场景图可选择 | 固定左生活、中书桌、右装扮三屏连续空间，不再选场景 |
| 当前状态 | 单一角色状态与百分比环 | 以破壳时间为起点，每 5 小时一个小状态；显示每日心情与此刻状态，不显示百分比 |
| 外出 | 仍停留在可互动场景 | 家里留空，只显示旅行/打工/上学文字和写信入口 |
| 对话 | 独立聊天页面 | 仅在允许说话的居家小状态中原地出现输入框，取消独立聊天路由 |
| 原生动作 | 每场景多个热点 | 每个小状态只保留一个原生动作，按时段幂等 |
| 回忆 | 场景反馈为主 | 动作生成一次性纪念品；外出回家后带回，回信进入明信片；每日推荐一张出生收藏卡 |
| 魔法窗 | 普通场景热点 | 右屏窗边状态可进入远方画面，并有明确回到房间路径 |
| 装扮 | 无画图转译 | 右屏进入装扮画布，每天固定 3 次，支持空、失败、生成中、结果、重复进入状态 |

## 状态与数据边界

- demo 数据存放在账号隔离的 `eggbabe_post_hatch_v36` 命名空间，用于完整体验与幂等回归。
- live 不推断服务端业务结果。服务端时间不可用、接口未接入或响应不完整时展示失败状态和重试入口。
- live 需要提供当前状态、原生动作、寄信、回忆、装扮状态、创建装扮和移动装扮七个端点；当前前端适配器名称分别为 `getPostHatchHome`、`performPostHatchAction`、`sendPostHatchLetter`、`getPostHatchMemories`、`getPostHatchDecorations`、`createRoomDecoration`、`moveRoomDecoration`。
- AI 场景内对话继续经过输入安全检查、正式回复适配和输出安全审核；demo 只使用已审核兜底文案。
