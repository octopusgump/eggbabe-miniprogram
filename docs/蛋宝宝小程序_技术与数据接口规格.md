# 蛋宝宝普通小程序 · 技术与数据接口规格

| 项 | 内容 |
|---|---|
| 适用产品 | eggbabe 微信普通小程序 |
| 对应主 PRD | V3.5 |
| 文档状态 | 当前有效 |
| 技术负责人 | 王敏（CTO） |
| 前端范围 | 页面、状态、services 适配层 |
| 后端范围 | 鉴权、正式数据、业务时间、内容安全与接口 |

> 本文定义普通版 live 技术范围及 develop 开发验收隔离。未来游戏版字段不得预埋成可运行的生产逻辑。

## 1 · 技术边界

- 前端不得生成正式用户 ID、业务时间、破壳结果或激活码判定。
- 正式写入必须等待服务端确认，禁止假成功。
- 所有请求携带 `mode=live/demo`；服务端拒绝跨模式数据。
- demo 使用独立命名空间，不进入 live 数据表和指标。
- H5 只负责收藏卡渲染和导出，不生成随机名字、插画或业务时间。
- 货币、库存、掉落、关系成长和任务清单接口不属于普通版；孵化动作记录属于本期普通版。

## 2 · 普通版 live 数据白名单

| 数据域 | 核心字段 | 说明 |
|---|---|---|
| 用户 | `user_id`、微信身份映射、头像 URL、资料、状态 | 服务端唯一 |
| 实体蛋绑定 | `egg_id`、`user_id`、激活码 ID、原型、款式、绑定时间 | 一账号一蛋 |
| 生命周期 | `egg_id`、阶段、预计破壳时间、修炼值、承接状态、服务端时间 | 修炼值由服务端权威计算 |
| 孵化动作 | `egg_id`、`module`、题目 / 选项、`server_date`、写入时间、本次修炼值 | 服务端幂等 |
| 愿望记录 | 题目 / 选项、答题日期 | 仅用于固定回应与孵化回顾，不做画像 |
| 收藏卡 | `record_id`、`egg_id`、身份编号、破壳日、固定素材 | 一蛋一份 |
| 对话 | 会话 ID、消息、内容安全结果、创建时间 | 按隐私政策保存 |
| 定性状态 | 状态 ID、文案、生成日期、来源 | 无心情数值 |
| 蛋壳创作 | 母版版本、颜色、图样、贴纸、笔迹操作、预览 URL | 不含上传图片 |
| 激活码 | 类型、状态、使用上限、使用者、核销时间 | 服务端核销 |
| 账户注销 | 申请时间、冷静期、取消 / 执行状态 | 可审计 |
| 必要埋点 | 事件名、用户、会话、服务端时间、必要属性 | 仅白名单事件 |

普通版 live 禁止数据以[合规清单 C-01–C-10](./蛋宝宝普通小程序_合规与提审清单.md)为唯一规范。技术实现必须拒绝对应的成长 / 任务、货币、库存、掉落和收集解锁写入。

## 3 · 通用接口约定

### 3.1 请求公共字段

```json
{
  "request_id": "uuid",
  "mode": "live",
  "client_version": "<实际小程序版本>",
  "session_id": "server-issued-or-validated"
}
```

- `request_id` 用于写操作幂等。
- `mode` 必须由构建目标和服务端共同校验，不能只依赖页面参数。
- 客户端时间只能用于动画，不作为业务判定。

### 3.2 响应公共字段

```json
{
  "success": true,
  "request_id": "uuid",
  "server_time": "2026-07-23T12:00:00+08:00",
  "data": {},
  "error": null
}
```

错误至少包括：未登录、参数错误、内容安全拒绝、激活码无效、重复核销、账号已绑定、写入冲突、网络超时、服务异常。

## 4 · 核心 service 接口

| Service | 接口 | 服务端职责 |
|---|---|---|
| auth | 登录 / 刷新会话 | 身份映射、会话签发 |
| activation | 校验并核销激活码 | 原子核销、防重、防伪、风控 |
| egg | 获取蛋与生命周期 | 服务端阶段和权威时间 |
| hatch | 获取 / 承接破壳结果 | 固定结果、幂等生成、失败重试 |
| record | 获取收藏卡数据 | 一蛋一份、固定编号 |
| drawing | 保存 / 读取蛋壳创作 | 版本冲突、跨设备同步 |
| incubation | 获取修炼手册 / 提交孵化动作 | 北京时间、内容日、连续登录压缩、修炼值与破壳门槛 |
| status | 获取定性状态 | 按服务端自然日稳定返回 |
| chat | 内容安全、生成回复 | 输入输出双检、危机兜底 |
| account | 更新资料 / 注销 | 冷静期、撤销、删除流程 |
| analytics | 批量事件上报 | 白名单过滤、服务端时间 |

普通版 service 层不得暴露 `currency`、`shop`、`inventory`、`drop`、`growth` 或 `task` live 方法。

激活码核销事务必须同时校验账号未绑定、码状态与配额，并在绑定成功后才消耗额度。个人码还要校验不可自用和一次性使用；审计字段按主 PRD §4.3 保存。

## 5 · 业务时间

- 单一权威时间：服务端北京时间 UTC+8。
- 生命周期、破壳、每日状态、订阅消息均由服务端时间决定。
- 客户端设备时间错误、切换时区或重装不能改变业务结果。
- 服务端响应返回 `server_time` 便于前端展示和诊断。

### 5.1 孵化动作接口

- `getIncubationManual`：输入 `egg_id`，返回 `server_date`、`content_day`、`unlocked_modules`、修炼记录、主动 / 被动 / 总修炼值、`hatch_at` 与破壳门槛。
- `getIncubationPractice`：输入 `egg_id`、`module`，返回 `server_date`、当天原记录，以及许愿池题目或修炼课堂选项。
- `submitIncubationAction`：输入 `egg_id`、`module`、`question_id`、`option_id` 与模块必要载荷。首次成功返回 `incubation_points_added` 与新 `hatch_at`；重复返回 `code=already_done`、原记录与当前 `hatch_at`。
- 被动修炼值按每满 24 小时增加 10 点；主动修炼值按 V3.5 固定表增加，总值上限 100。
- 每日唯一索引为 `(egg_id, module, server_date)`；一次性唯一索引为 `(egg_id, module)`。
- 达到 100 后进入 `HATCHABLE`；昵称、出生礼物与孵化回顾仍是执行破壳的强制门槛。
- 连续登录压缩只由服务端计算并返回解锁结果，客户端不得显示或暗示连续登录机制。

## 6 · 蛋壳创作数据

建议结构：

```json
{
  "egg_id": "egg_xxx",
  "base_asset_id": "egg_base_day",
  "base_version": "v2.26",
  "color_token": "mint",
  "color_alpha": 0.32,
  "pattern_instances": [],
  "stroke_operations": [],
  "canvas_version": 1,
  "preview_asset_url": "https://cdn.eggbabe.com/...",
  "mode": "live"
}
```

- 坐标均相对蛋体画布归一化。
- 结构化编辑数据是事实来源，预览图只是缓存。
- 不保存用户上传图片字段。
- `egg_base_day.webp` 的 RGB + Alpha 必须原样保留。

## 7 · 收藏卡与 H5

- 收藏卡数据由后端注入 H5。
- H5 不生成随机名字、性格、插画或业务时间。
- 同一 `record_id` 重试时返回同一数据和素材。
- H5 使用三段式水彩模板：顶部名字 / 原型，中部固定插画，底部生日 / 星座 / 身份信息和一句自我介绍。
- 数据区不超过卡面约 1/3，字段不重复，文字对比度达到 WCAG AA。
- 标题字体使用自托管 OFL 版 `ZCOOL KuaiLe`，缺字回退 `PingFang SC`。
- web-view 只加载已备案 HTTPS 业务域名。
- H5 canvas 通过 `postMessage` 回传小程序，再由 `wx.saveImageToPhotosAlbum` 保存；服务端固定图片 URL 为备选。
- 导出图包含身份编号和小程序码。
- demo 卡带 `mode=demo`，不进入 live 卡册。
- “收藏卡”仅为用户名称；内部表可命名 `digital_record`。

## 8 · 对话与内容安全

- 用户输入展示 / 落库前检测。
- 模型输出展示 / 落库前检测。
- 检测失败使用安全兜底，不回显违规内容。
- 危机内容进入专门回复策略和必要的人工审计标记。
- 不把对话内容转换成好感度、关系等级或剧情解锁条件。
- 成本 / 频率限制只作为服务护栏，不包装成体力或次数资源。

## 9 · 普通版埋点白名单

### 9.1 通用属性

`event_name`、`user_id`、`mode`、`server_ts`、`session_id`、`egg_id`、`stage`、`source_channel`。

### 9.2 允许事件

| 事件 | 用途 |
|---|---|
| `app_open`、`login_result` | 进入与授权漏斗 |
| `add_egg_page_view`、`activation_submit`、`activation_result`、`egg_bound` | 实体蛋绑定 |
| `hatch_home_view`、`companion_interaction`、`egg_doodle_save` | 自由互动可用性 |
| `hatch_receive_start`、`hatch_record_generated`、`record_save`、`record_share` | 破壳与纪念价值 |
| `role_home_view`、`scene_enter`、`interaction_point_tap` | 场景入口可用性，不建兴趣画像 |
| `chat_open`、`chat_message_sent`、`chat_reply`、`chat_session_end` | 对话质量与回访 |
| `daily_status_generated`、`daily_status_viewed`、`daily_status_to_chat` | 定性状态效果 |
| `data_write_fail`、`network_error`、`multi_device_conflict` | 技术诊断 |
| `account_delete_request`、`account_delete_cancel` | 注销流程 |

### 9.3 禁止事件

不发送 `currency_*`、`shop_*`、`item_*`、`scene_card_*`、`card_set_complete`、`ecommerce_unlock`、`incubation_progress_*`、`task_*` 或类似事件。允许按白名单记录单次 `companion_interaction` 的模块、结果、题目与选项 ID，但不发送答案正文或画像维度。

## 10 · demo / live 隔离

### 10.1 构建映射

| 微信环境 | 模式 | 数据来源 | 后端未接入时 |
|---|---|---|---|
| `develop` | `demo` | 固定本地验收 fixture | 允许测试已批准的普通版完整流程 |
| `trial` | `live` | CTO 测试 / 预发布服务 | 明确阻断，不回退 demo |
| `release` | `live` | CTO 正式服务 | 明确阻断，不回退 demo |

- 模式只由微信 `envVersion` 在启动时决定，没有用户界面开关。
- 无法识别环境时按 `release/live` 处理。
- develop 的用户、实体蛋、会话、同步队列、收藏卡和埋点使用 `eggbabe_demo_*` 独立命名空间。
- develop 收藏卡使用包内固定素材并保留 `mode=demo`，不得进入正式 H5 或正式卡册。
- trial / release 不得读取、迁移或上传 demo 数据。

### 10.2 数据边界

| 维度 | live | demo |
|---|---|---|
| 用户 | 正式身份 | 临时体验身份 |
| 激活码 | 正式核销 | 固定测试码 |
| 数据库 | 正式表 | 独立命名空间 / 库 |
| 收藏卡 | 正式记录 | 带 demo 标记 |
| 经济历史演示 | 不存在 | 仅独立构建可访问 |
| 指标 | 纳入 | 永不纳入 |
| 生命周期 | 长期保存 | TTL 或一键清理 |

普通版提审包不得包含可由用户访问的 demo 或游戏化入口；`trial` / `release` 自动化必须验证 demo 无法开启。

## 11 · 管理后台

普通版最小后台：

- 激活码创建、上限、停用、查询和核销记录。
- 用户与实体蛋绑定查询。
- 生命周期和硬件异常人工承接。
- 定性状态 / 节令内容配置。
- demo 数据清理。
- 普通版指标看板。
- 注销状态和内容安全审计。

不建设货币、商店、背包、卡池、掉落或成长后台。

## 12 · 非功能要求

- 所有正式写接口支持幂等。
- 数据表设置唯一约束和必要索引。
- 敏感字段最小权限访问。
- 关键后台操作留痕。
- 素材通过备案 CDN 下发；首屏保留必要兜底素材。
- 写入失败明确提示并允许重试。
- 离页清理计时器、动画和未完成请求。

## 13 · 技术验收

- [ ] 普通版服务层没有游戏化 live 方法。
- [ ] 所有业务时间来自服务端。
- [ ] 每日动作并发重复请求只有一条记录且只增加一次修炼值。
- [ ] 一次性动作再次提交不重复增加修炼值，总修炼值不得超过 100。
- [ ] 许愿答案只用于固定回应与孵化回顾，不生成画像或人格字段。
- [ ] 写操作都有 `request_id` 并通过幂等测试。
- [ ] demo 与 live 隔离测试通过。
- [ ] develop 可以完成授权、绑定、孵化互动、破壳和收藏卡页面链路。
- [ ] trial / release 在后端未配置时阻断，且不写入 `eggbabe_demo_*`。
- [ ] 收藏卡重试结果固定。
- [ ] 内容安全输入 / 输出双向测试通过。
- [ ] 普通版埋点白名单和禁止列表验证通过。
- [ ] 注销与删除流程经过端到端测试。
- [ ] 网络失败、写冲突、多设备和硬件异常有明确兜底。
