## 2. 语气基准（对齐现有体系）

- **标题**：短邀请、可扫读、彼此句式不撞型；避免整表「想听你说×的事」套娃。
- **正文**：**一句**中文，UI 层外加引号；语气对齐日常听你说邀请——「想听你说件小事」/「有几件小事想和你聊聊，你来选就好。」——节庆版更**喜庆、轻快**，并**轻引导**开信、选小事、领星（不写成任务清单）。
- **活动**：节日行默认仍指向 **听你说** 类「选小事聊聊」；开信基础星 / 首组 +10 规则以 PRD §5.1、§6.6 为准，文案只点一下「开信」「领星」即可。

---

## 3. 语气样例（4～5 条，供定调）

公历触发日按 **2026 年**常见农历换算（实施前需与香港天文台或运营表再核一次）。正文为稿内字面句；产品上由信纸组件外包一层 `"…"`。

| 日期 / 节日 | 标题 | 正文（软邀一句） |
| --- | --- | --- |
| 公历 · 2026-01-01（元旦） | 新年第一封信，轻轻的 | 开封信，选一件开头的小事，星星也会跟过来。 |
| 农历 · 春节 · 2026-02-17 | 先把年味说给你听 | 今天聊点热乎的就好，你来选题目，顺手收下今天的星。 |
| 农历 · 元宵 · 2026-03-03 | 花灯亮了，借你两分钟 | 灯下的几道题随你点，答完就能领星。 |
| 农历 · 端午 · 2026-06-19 | 龙舟鼓点前，先碰个头 | 挑一句想聊的，开信我们就开始。 |
| 农历 · 中秋 · 2026-09-25 | 月亮圆了，耳朵借我一会儿 | 团圆里藏着几道小题，你来选，聊完领颗星。 |

### 3.1 定调自检（草案）

| 维度 | 说明 |
| --- | --- |
| 标题区分度 | 分别用「新年/年味/花灯/龙舟/月亮」锚点，无「想听你说…的事」重复句式。 |
| 正文软邀 | 均为一句、可引号包裹；含「选/聊/开信/领星」轻引导，无命令式任务链。 |
| 喜庆度 | 偏暖、过节感；未写具体习俗科普，避免占信纸篇幅。 |
