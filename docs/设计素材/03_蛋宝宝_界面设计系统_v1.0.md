# 蛋宝宝小程序界面设计系统 v1.0

> 用途：给设计、前端和评审一份可单独转发的界面规则。下载本文件即可对照，不必再翻整份产品文档。
>
> 更新日期：2026-11-16（北京时间）
>
> 适用范围：微信小程序界面。不覆盖官网、包装、品牌 VI，也不覆盖场景镜头和图片生产。

## 怎么用这份文档

1. 做新页面或改控件时，先用本文的颜色、字体、形状、动效和组件。
2. 破壳前后的页面流程、聊天规则、绘画保存和回忆内容，仍看 [01_蛋宝宝_设计规范.md](01_蛋宝宝_设计规范.md) 与对应 PRD。
3. 旅行底图的镜头和景别，仍看 [02_IAA陪伴_旅行底图设计规范_v1.0.md](02_IAA陪伴_旅行底图设计规范_v1.0.md)。
4. 颜色和控件尺寸与代码不一致时，以本文和 `miniprogram/app.wxss` 为准。主 PRD §16 里的另一套品牌色（`#3F5A47`、`#ACC861`、`#F1EC9A`、`#FFC5BA`、`#C33F36`）是旧口径，不要再拿来做界面。

本文只收录已经在设计规范或现有组件里确认、并且可以跨页面复用的规则。场景页上的季节渐变、首页氛围色属于页面例外，不要回写成全局色。

## 1. 原则

1. **一个页面只有一个视觉焦点。** 场景页以角色和空间为主，回忆详情以物件或明信片为主，工具和说明退到次级。
2. **界面服务于陪伴。** 安静、温暖、可触摸。避免通用后台卡片墙、游戏化图鉴和奖励话术。
3. **图片承载场景，原生界面承载信息。** 标题、日期、正文、按钮和状态不要烘焙进场景图。

## 2. 颜色

色值目前写在各页面样式里，`app.wxss` 顶部有同名对照。下表是唯一允许的界面色。需要新语义色时，先补进本表，再使用。不要在页面里另写近似绿、近似灰。

### 2.1 主色与中性色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| ink | `#002900` | 主按钮、主描边、导航标题 |
| ink-pressed | `#001A00` | 主按钮按下 |
| text | `#1A1A1A` | 一级文字 |
| text-muted | `#5C5C5C` | 二级文字 |
| text-faint | `#8C8C88` | 三级文字、说明、分组标签 |
| canvas | `#FFFFFF` | 卡片、导航条 |
| page | `#FAFAF8` | 页面底 |
| hairline | `#E5E3DF` | 分隔线、卡片边 |
| hairline-strong | `#CFCBC4` | 需要更清楚的分隔 |
| ink-surface | `#E5EBE5` | 列表按下、中性提示底 |

### 2.2 品牌点缀

只作小面积点缀和状态色，不要铺成大段正文底。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| egg-green | `#9DB65B` | 品牌绿，例如开关开启 |
| egg-yellow | `#EDE78E` | 蛋壳渐变色 1 |
| egg-pink | `#F4B9AE` | 蛋壳渐变色 2 |

### 2.3 语义底与其上的文字

| 名称 | 底色 | 文字 | 用途 |
| --- | --- | --- | --- |
| green | `#F5F8ED` | `#54632C` | 绿色提示卡片 |
| yellow | `#FAFAEF` | `#6E6B35` | 黄色提示卡片 |
| pink | `#FFF6F5` | `#80625D` | 回忆、羁绊区块 |
| error | `#D9463C` | `#FFFFFF`（按钮）/ 底 `#FDECEA` | 危险操作、错误提示 |

回忆区块使用桃粉底和对应深字。`card` 组件目前提供 `base`、`tint-green`、`tint-yellow`；桃粉回忆区按上表色值使用，不要改成绿色卡片。

### 2.4 阴影

阴影带一点墨绿，不用纯黑重阴影。

| 名称 | 值 | 用途 |
| --- | --- | --- |
| shadow-raised | `0 2rpx 4rpx rgba(0, 41, 0, 0.06), 0 4rpx 8rpx rgba(0, 41, 0, 0.04)` | 白卡片 |
| shadow-floating | `0 8rpx 24rpx rgba(0, 41, 0, 0.10)` | 蛋形头像等浮起元素 |

## 3. 字体与尺寸

- 中文字体栈：`PingFang SC, Helvetica Neue, Microsoft YaHei, sans-serif`。
- 字重最高 **600**。PingFang SC 没有真正的粗体，不要写 `700`。
- 设计稿按 375px 宽绘制。小程序里 **1px = 2rpx**，样式里写 rpx。
- 正文优先 `24–30rpx`，辅助文字不小于 `20rpx`。标题靠字号和留白，不靠加粗。

现有组件里已经在用的字号：

| 角色 | 字号 | 字重 | 出现位置 |
| --- | --- | --- | --- |
| 标题 / 主按钮 / 列表主文 | `30rpx`（15px） | 600 | 导航标题、主按钮、列表行 |
| 次级说明 | `24rpx`（12px） | 常规 | 列表右侧值、开关说明、分组标签 |
| 轻提示 | `22rpx` | 600 | 标准轻提示，单行 |
| 小按钮 | `28rpx` | 500 | `button` 的 `size=small` |

还没有完整的展示字阶。场景页上的大标题（例如空态 `42rpx`）是页面排版，不要当成新的全局标题 token。

## 4. 形状、间距与触控

- 单独一个紧凑操作：`112rpx × 112rpx` 正圆。
- 两个及以上同组操作：放进同一个胶囊，每一段高、宽 `112rpx`。
- 文字主按钮：高 `96rpx`，圆角 `999rpx`，字重 600。
- 小文字按钮：高 `80rpx`，字号 `28rpx`，字重 500。
- 卡片、输入框、确认弹层、底部面板可以用中大圆角。卡片标准是圆角 `32rpx`、内边距 `48rpx`。
- 按钮只用正圆或胶囊。不要把按钮做成中圆角矩形。
- 蛋形只用于头像和破壳相关视觉：`50% 50% 50% 50% / 58% 58% 42% 42%`。不要拿来当通用圆角。
- 列表行最小高度 `104rpx`（52px），左右内边距 `40rpx`。开关行上下内边距 `28rpx`。
- 页面底部留出安全区：在内容垫高之外再加上 `env(safe-area-inset-bottom)`。

## 5. 动效

- 常规按压：`160–180ms ease-out`，`scale(0.98)`，透明度约 `0.9`。
- 只对**按状态新增或移除**的卡片使用动态卡片：进入 `240ms ease-out`，透明度淡入并上移 `12rpx` 归位；离开 `180ms ease-in`，淡出并下移 `8rpx`。常驻列表不要每次进页都播。
- 回忆卡高光最多 `400ms`。更长、更明显的动画只留给破壳等情绪节点。
- 系统开启「减少动态效果」时，去掉位移、缩放、旋转和循环动画，保留颜色或透明度能表达的静态状态。

## 6. 组件

路径都在 `miniprogram/components/`，底部导航在 `miniprogram/custom-tab-bar/`。

### 6.1 按钮 `button`

| 变体 | 外观 |
| --- | --- |
| `primary` | 实心 `#002900`，白字 |
| `secondary` | 透明底，`3rpx` 实线 `#002900` |
| `secondary-soft` | 透明底，`3rpx` 描边 `rgba(0, 41, 0, 0.24)`，字仍为 `#002900` |
| `danger` | 实心 `#D9463C`，白字 |
| `disabled` | 不响应点击，整体透明度 `0.4` |
| `size=small` | 高 `80rpx`；默认为 `96rpx` |

按下态统一为透明度 `0.9` 加 `scale(0.98)`。

### 6.2 卡片 `card`

| tint | 外观 |
| --- | --- |
| `base` | 白底、`1rpx` 分隔线、抬起阴影 |
| `tint-green` | `#F5F8ED` |
| `tint-yellow` | `#FAFAEF` |

### 6.3 导航 `nav-bar`

- 行高 `112rpx`，与圆形返回按钮同高。
- 标题 `30rpx` / 600 / `#002900`，过长省略。
- 默认白底加底部分隔线。画布页可改成页面底色 `#FAFAF8` 并去掉分隔线。
- 返回按下：底 `#E5EBE5`，`scale(0.98)`。

### 6.4 列表

- `list-row`：最小高 `104rpx`，主文 `30rpx`，右侧值 `24rpx` / `#8C8C88`，按下底 `#E5EBE5`，分隔线 `#E5E3DF`。
- `switch-row`：左标题 `30rpx`，说明 `24rpx` / `#8C8C88`，右侧为开关。
- `collapse-item`：问题标题用一级文字，分类标题用二级文字。

### 6.5 标准轻提示 `inline-notice`

用于已经发生、不需要用户再选择的短结果，例如「已清空，可以撤销」「蛋壳已更新」。同类反馈不要再做另一套颜色或形状。

| 属性 | 标准 |
| --- | --- |
| 文字 | `#FFFFFF`，`22rpx`，字重 600，单行 |
| 默认底 | `rgba(18, 21, 18, 0.72)` |
| 注意态 | 仍是白字；底 `rgba(39, 27, 23, 0.78)`，只用于失败或需要马上处理 |
| 容器 | 最小高 `64rpx`，左右内边距 `28rpx`，圆角 `999rpx` |
| 边与阴影 | `1rpx solid rgba(255, 255, 255, 0.16)`；`0 8rpx 24rpx rgba(0, 0, 0, 0.18)` |
| 质感 | 可以 `blur(12rpx)`，但不能靠模糊才读得清 |
| 动效 | 只淡入淡出，`180ms ease-out` |
| 时长 | 约 `1800ms`。不要倒计时、进度条，也不要挡住操作 |
| 交互 | `pointer-events: none`；语义用状态提示，不要做成按钮 |

文案用「结果 + 必要的下一步」，一句话。不要用「成功啦」「太棒了」。同一结果不要在导航状态、轻提示和系统 Toast 里各说一遍。

不要用轻提示替代这些界面：

- 需要确认或承担后果的操作：白色确认卡片或底部面板。
- 角色说话：既定对白气泡。
- 表单错误：贴在字段旁边。
- 持续加载、空态、可重试的失败：页面里的固定状态。

### 6.6 头像与底部入口

- `egg-avatar`：蛋形圆角，浮动阴影。只用于蛋形头像。
- 右下角「我的」入口：`112rpx` 正圆、白底、轻描边和模糊，按下 `scale(0.98)`。

## 7. 状态与无障碍

- 依赖网络或大图的页面，都要有加载、失败、重试，并且能返回。
- 顶部导航、底部操作和全屏内容避开安全区。
- 图形按钮提供可读的 `aria-label`。纯装饰层不进语义树。
- 错误、成功和保存不要只靠颜色区分，文案本身要说清状态。
- 开发用的切换器和说明只出现在开发环境，不进入体验版和正式版。

## 8. 不要放进这套系统的内容

这些规则仍然有效，但它们是产品流程或美术生产，不是可复用的界面 token。

- 破壳前房间、破壳后三屏生活空间、外出状态、聊天入口。
- 蛋壳绘画的笔刷档位、保存和二次确认流程。
- 全景尺寸、CDN、缺图时禁止串图。
- 旅行明信片的镜头、景别和生成锁定条件。
- 改动索引、候选图和开发验收页。

## 9. 尚未锁定

提炼时没有补造这些缺口：

- 样式里还没有集中的 CSS 变量文件，色值是按上表写死的。
- 没有完整字阶表，也没有统一图标库。
- 没有可用的深色模式色板。
- 部分场景页仍使用规范外的氛围渐变。那些是页面例外，新的信息界面不要跟着抄。
