# 破壳卡素材放置说明

H5 不根据图片文件名猜测款式，所有素材都通过 `asset-config.js` 显式映射。

- 角色透明图：`assets/figures/`，推荐 PNG/WebP，竖构图、透明背景，建议至少 1200 × 1600 px。
- 卡面背景图：`assets/posters/`，推荐 JPG/WebP，9:16 竖图，建议至少 1080 × 1920 px。
- 文件名建议：`角色代码__款式名`，例如 `YT__月白桂花款.png`。
- 同款限定批次可追加批次名，例如 `YT__月白桂花款__2026中秋限定.jpg`。

新增素材后，在 `asset-config.js` 的 `cards` 中加入对应 `figure_key` / `bg_key`。素材域名必须允许跨域读取，否则页面可以显示图片，但浏览器不能把它们绘制进分享长图。
