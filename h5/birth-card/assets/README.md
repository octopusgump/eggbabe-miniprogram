# 破壳卡素材放置说明

## MVP 最终素材方案

当前阶段采用“固定完整卡面主图”，不开发独立道具层，也不要求把角色身体、道具和背景拆开。

每张固定卡由三部分组成：

1. 一张完整 Hero 主图：角色 + 固定动作 + 固定道具 + 背景，作为不可变的卡片故事画面。
2. H5 信息与卡框：名字标题、生日、星座、MBTI、系列内编号和 `eggbabe` 字标。全局唯一编号进入分享图脚注，不放在卡面数据栏。当前不显示 `FUN FACT`、`STRENGTH`、血型、孵化品质、初始主人或性格长句。
3. 抽卡揭晓效果：卡背/遮罩、微光、上浮和轻量粒子；只在抽卡过程显示，不写入最终卡面素材。

现有 10 张玉兔水彩 JPG 均按 `composite-illustration` 管理，直接作为固定 Hero 主图使用，不进行角色抠图。其约 4:5 的画面比例与当前 H5 Hero 区基本一致。

只有在固定卡片业务得到验证，并且明确需要动态更换背景、自由装扮或视差动画时，才进入下一阶段拆分透明角色图和独立道具层。进入该阶段前须重新确认产品需求，不提前制作。

H5 不根据图片文件名猜测款式，所有素材都通过配置显式映射。

- 角色素材：`assets/figures/`。透明角色切图推荐 PNG/WebP；自带场景背景的完整插画可以使用 JPG，但必须在素材目录表中标记为 `composite-illustration`。
- 卡面浅底、圆角白边与三段式排版由 H5 模板生成，不需要提前制作整张背景海报。所有插画建议按 4:5 构图；若未来增加独立插画背景，可放 `assets/posters/` 并在 manifest 显式登记。
- 统一文件名：`{角色代码}__{系列}__{场景或款式}__v{两位版本号}.{扩展名}`。
- 示例：`YT__watercolor__bath__v01.jpg`、`KOI__classic__lucky-red__v02.png`。
- 角色代码固定大写，目前使用 `YT`、`KOI`；系列、场景和款式固定使用小写英文 `kebab-case`。
- 分隔符固定使用双下划线 `__`；禁止空格、中文文件名、`final`、`new` 等无法排序的版本词。
- 升级同一素材时只递增版本号，不覆盖旧文件，例如 `v01` → `v02`。

新增角色素材后，先登记到 `assets/figures/catalog.json`；真正用于破壳卡时，再在 `asset-config.js` 或远程 manifest 中配置对应 `figure_key` / `bg_key`。素材域名必须允许跨域读取，否则页面可以显示图片，但浏览器不能把它们绘制进分享长图。

当前玉兔水彩系列 JPG 自带背景，不应再叠加成“透明角色切图”，直接作为完整 Hero 插画使用。

套装清单独立保存在 `assets/sets/`。第一季玉兔套装使用 `YT-S01.json`，发布后清单号不得重排或复用。
