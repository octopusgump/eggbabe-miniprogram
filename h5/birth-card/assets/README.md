# 收藏卡插画素材说明

普通版收藏卡只展示与实体款式绑定的固定插画，不在 H5 中选择、组合或随机生成插画。

正式流程中，服务端根据 `card_id` 返回已确定的 `illustration_key` 与备案 HTTPS `illustration_url`；H5 和小程序原生兜底只负责按原值渲染。分享长图还需要服务端提供真实 `mini_program_code_url`。

`assets/figures/` 中的图片仅是历史美术源文件，不参与生产运行时映射。部署 H5 时可以不上传这些未引用文件；如需启用其中一张，必须先由内容团队确认其对应实体款式，再上传到受控 CDN，由服务端收藏卡记录返回固定 URL。

素材要求：

- 建议按 4:5 构图，使用 PNG、WebP 或 JPG；
- 不含价格、稀有度、系列进度、奖励或交易暗示；
- 域名必须已备案并允许 H5 跨域读取，否则无法绘制分享长图；
- 更新同一实体款式的素材时需保留版本记录，避免同一收藏卡在不同时间展示不同结果。
