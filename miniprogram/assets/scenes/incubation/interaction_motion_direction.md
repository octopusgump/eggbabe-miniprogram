# 蛋宝宝 C 类互动与动效方向

## 固定约束

- 镜头、房间、家具、圆窗、U 形孵化窝与靠枕始终锁定，不发生变形或位移。
- 蛋宝宝始终有重量：底部接触阴影随压缩、移动和呼吸同步变化，不允许旋转、飞起、悬浮或离开窝垫。
- 动效使用柔和缓入缓出、低幅度、低亮度；不使用爆炸粒子、强闪烁、倒计时、奖励提示或任务完成状态。
- 主要交互区域、蛋宝宝、时钟和日历不被天气或光线表现层遮挡。

## 触摸陪伴

| 状态 | 建议动作 | 建议节奏 |
| --- | --- | --- |
| 待机 | 蛋宝宝上下约 2–3px 缓慢呼吸，接触阴影同步收缩/扩散 | 3.6–4.8s 循环，ease-in-out |
| 轻触 | 左右柔和摆动一次；触点出现 3 颗小光点，快速淡出 | 700–900ms |
| 长按 | 蛋宝宝缓慢向靠枕靠近；窝垫和靠枕微压缩后回弹；蛋壳亮度渐升 | 按住 1.2–1.8s；松手后 700ms 恢复 |
| 安静陪伴 | 呼吸节奏逐渐贴合房间灯光；窗帘仅做极小幅摆动 | 6–10s 低频循环 |

## 说话身体反应

1. 轻轻晃动：左右 3–5° 小幅摆动，回到中心。
2. 开心大晃：向上轻弹约 4px，再向靠枕方向柔和落回，接触阴影同步加深后恢复。
3. 壳身发光：暖白光晕从中心扩散，最大透明度克制，随后淡出。
4. 颜色变化：只改变临时色温层，短暂偏暖，结束后回到原始外观。
5. 壳内咚咚：蛋壳连续两次极小鼓动，阴影同步呼吸式变化。

## 季节、天气与擦窗

- 春季：窗帘极小摆动，嫩叶缓慢摇曳。
- 夏季：窗外绿叶产生极轻视差，光斑缓慢移动。
- 秋季：室内光线缓慢变暖，树叶仅轻微摇动，不出现飞舞落叶。
- 冬季：玻璃边缘出现非常淡的冷凝光泽，不自动飘雪。
- 雨天：玻璃叠加少量纵向雨丝，室内亮度轻微降低。
- 雪天：仅在 snow 状态显示少量、慢速雪花。
- 阴天：窗外亮度降低，云层缓慢横向移动。
- 擦窗：滑动区域的雾气蒙层按手指路径逐渐擦除；松手后保持清晰，不立即恢复。

## 轻量创作

- 绘画轨迹：圆润、低亮度、略滞后跟随手指，结束后停留片刻再淡出。
- 保护圈：轨迹闭合成柔和光环，不形成强烈魔法阵。
- 小星星：只生成一颗简单光点或极简四角星，轻落到蛋壳附近后消失。
- 选色：以柔和色彩过渡改变临时光晕，不闪烁，不产生强烈彩虹。

## 破壳四阶段

1. 呼吸幅度略增，出现初始裂纹。
2. 裂纹缓慢延伸，缝隙透出克制暖白内光；靠枕和软窝轻微回弹。
3. 内光逐渐变亮，少量碎片向外移动，不高速爆炸。
4. 柔和白光遮罩短暂覆盖主体，转场至角色揭晓页；角色在遮罩前不提前露出。

## 唯一可选视频

如需视频，只制作一条破壳关键短片：固定镜头与房间，蛋宝宝始终坐落在半开放 U 形窝中并靠着暖燕麦色靠枕；呼吸、裂纹、暖白内光、软垫压缩回弹和少量碎片依次出现，最后由柔和白光进入下一页。禁止额外角色、悬浮、爆炸、快速剪辑、强闪光和大量粒子。
