# 锦鲤卧室日常动作全景

本目录为已确认的 Boon Koi（锦鲤）正式动作全景，共 24 张：八个日常场景各具 `day`、`sunset`、`night` 三个时段。

| 状态 | 文件动作名 | 交互规则 |
| --- | --- | --- |
| 睡觉 | `sleep`（文件历史名 `nap`） | 锦鲤侧躺、闭眼，保持自然鱼身与靴子。 |
| 小憩 | `lazy` | 锦鲤清醒并在床上放松休息，与闭眼睡觉保持独立。 |
| 发呆 | `stare` | 锦鲤站在中央圆垫上放空，不持动作道具。 |
| 阅读 | `read` | 站立读书；两只脱离身体的淡青蓝灵魂手托书。 |
| 游戏 | `game` | 两只脱离身体的淡青蓝灵魂手操作手柄。 |
| 看窗外 | `window` | 自然鱼鳍靠窗，保持尾鳍可见。 |
| 画画 | `draw` | 一只脱离身体的淡青蓝灵魂手持笔。 |
| 听音乐 | `music` | 自然鱼鳍抱住收音机，闭眼聆听。 |

- 所有图均为 `2823×1672` 不透明 WebP，角色、动作与道具已烘焙。
- 文件名为 `home_bedroom_{nap|lazy|stare|read|game|window|draw|music}_{day|sunset|night}_v01.webp`。
- `nap` 只是睡觉资源沿用的历史文件名；产品“小憩”使用独立内部键 `lazy`，不得复用睡觉图片。
- 目录由 `project.config.json` 排除出主包，运行时应通过 `environmentCdnBase` 加载。
- 生成源稿和早期审核稿保留在同级 `candidates/`，不作为运行时资源引用。
- 当前版本不维护季节或天气扩展矩阵；历史扩展图已移出本资源树。
