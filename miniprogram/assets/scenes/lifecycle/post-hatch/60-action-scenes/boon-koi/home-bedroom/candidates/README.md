本目录只存放审核候选，不由运行时配置引用。

## 已确认的动作原则

- **睡觉（内部键 `sleep`，文件历史名 `nap`）**：锦鲤必须是一条自然侧躺的鱼，身体水平、闭眼，尾鳍与芥末黄靴自然可见；不得坐起或使用人形姿态。采用 `home_bedroom_nap_day_boon-koi_candidate_v02.webp`。产品“小憩”使用独立内部键 `lazy`，不得复用本候选。
- **阅读（read）**：采用站立阅读。书本由两片胸鳍托住，书底在黄色靴子上方，必须留出可见间隙；书本不得与靴子相交、卡入或被遮挡。采用 `home_bedroom_read_day_boon-koi_candidate_v03.webp`。
- **游戏（game）**：锦鲤没有实体手臂或手指，不能直接用手操作手柄；以意念投射两只脱离身体的淡青色半透明灵魂手操作手柄。

## 统一造型锁定

- 严格使用 Boon Koi（锦鲤）标准造型：奶油白椭圆鱼身、细鳞织物压纹、棕橙色鱼鳍、奶油白分叉尾、极短双腿与芥末黄色靴子。
- 不得出现兔耳、人形手臂或其他新增结构；物品交互只可由胸鳍完成。
- 每张候选必须保持卧室三屏全景的镜头、构图、角色落点与现有道具不变，并输出 `2823×1672` 不透明 WebP、单张小于 1 MB。
