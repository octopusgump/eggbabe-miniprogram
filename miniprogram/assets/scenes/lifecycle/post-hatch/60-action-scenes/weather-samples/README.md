# Post-hatch weather action samples

Seventy-two opaque 2823×1672 WebP action panoramas: every pre-hatch environment state has one action image for Jade Moon Rabbit and one for Boon Koi. They are complete room-and-character composites, not transparent character layers and not formal `scene-sets` backgrounds.
